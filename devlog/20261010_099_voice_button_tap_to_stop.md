# 099 — 🎙 짧게 누르기 = 조용히 정지

2026-10-10 · P12 후속 · 사용자: "마이크 버튼을 짧게 눌렀다 떼면 그게 현재 정지 버튼 역할을 하거든. 짧게 눌렀다 떼면 그냥 정지만 하고 아무 메시지도 보여줄 필요 없어."

## 지금까지
🎙 를 누르는 순간 메트로놈을 멈춘다(`stopForCommand`, P12 §4.2). 그래서 짧게 눌렀다 떼는 것이 사실상 정지 단추로 쓰였다.
그런데 그때도 듣기가 걸려 "🎙 …" → "알아듣는 중…" 이 뜨고, 0.6초 꼬리 뒤에 "말을 못 들었어요" · "못 알아들었어요"가 남았다.

## 바꾼 것
- **0.4초(`VOICE_TAP_MS`) 안에 떼면 정지 단추로 본다**
  - 듣기를 `cancel()` 해 결과 · 오류가 오지 않게 하고, 글자를 지우고, 아무것도 띄우지 않는다
  - 멈추기는 누르는 순간 이미 했다(시작 마디를 고르는 중이면 그대로 두는 것도 같다)
- **누른 채로 0.4초가 지나야 "🎙 듣는 중…"을 띄운다**: 누르자마자 뜨던 "🎙 …"을 없앴고, 서비스의 준비 알림(`onListening`)도 0.4초 전에는 띄우지 않는다. 짧게 누를 때 글자가 번쩍이지 않는다
  - 말하기 시작하면 중간 결과(`onPartial`)는 전처럼 바로 뜬다 — 누른 채 말하는 중이므로
- 0.4초: 짧게 누르기는 보통 0.1 ~ 0.3초, 한 낱말 명령("정지", "시작")도 누르고 말하고 떼면 0.6초를 넘는다
- 남은 것: 음성 서비스의 시작음(알림 채널)은 짧게 눌러도 난다 — 누르는 순간 듣기를 걸어야 말의 첫머리를 놓치지 않으므로 그대로 둔다
