# 070 — 연주자도 지금 시스템 표시 · 지휘자가 끝내면 연주자도 합주 끝 (P10)

## 1. 연주자도 지금 시스템을 연하게 (사용자 요청)

- 새 신호 `follow_position` {file, measure} — 지휘자 마이크 추적의 지금 마디 번호. **시스템이 바뀔 때만** 보낸다(쪽당 몇 번). 추적을 멈추면 `measure = 0`(지움). 옛 앱은 무시
- 연주자는 **자기 악보 분석**(같은 PDF → 같은 마디 번호)에서 그 마디의 쪽 · 시스템을 찾아, 지휘자와 같은 연한 노랑으로(`ScoreOverlayView.systemFrame`)
  - 두 쪽 차례 넘김(3 | 2)이어도 맞게: 그 쪽이 놓인 자리(왼 0 · 오 1)로 마디의 쪽 번호를 바꿔 `ScoreOverlayGeometry.boxes` 를 부른다(쪽 크기가 같다고 본다)
  - 마디 분석은 뒤에서 조용히 읽는다(`loadScoreMeasures(announce = false)` — 마디 수 토스트 없음). 분석이 없는 기기는 쪽 테두리만
- 지휘자 쪽: `micSentSystem`(쪽 × 1000 + 시스템)으로 바뀔 때만 보냄

## 2. 지휘자가 합주를 끝내면 연주자도 끝 (사용자 요청)

- 새 신호 `ensemble_end`. `GlobalCollaborationManager.deactivateCollaborationMode()` 가 **지휘자였으면 서버를 끄기 전에** 보내고 0.2초 기다린다 — 파일 목록의 합주 종료 · 앱 종료 모두
- 연주자: 받으면 **따로 스레드에서** 합주 모드를 끝내고(받는 스레드가 곧 정리될 클라이언트 것이라) 메인 스레드로 알림 → 파일 목록은 상태 줄, 뷰어는 쪽 테두리 · 시스템 표시 · 합주 메트로놈을 정리하고 "지휘자가 합주를 끝냈습니다 — 합주 모드 종료"
- 저장된 모드도 "none" 이 되어 다시 붙으려 하지 않는다. 옛 앱은 무시(지금처럼 연결 끊김만)
- 지휘자가 지휘자 모드를 다시 켜도(안에서 한 번 끝내므로) 연주자가 한 번 끊긴다 — 다시 시작과 같아 두었다

## 3. 테스트

`follow_position` 왕복(0 = 끝), `ensemble_end` 액션 이름 — 단위 테스트 321개
