## 0. 먼저 한 것 — ⌨️ 글자로 명령 뺌
P12 1단계에서 음성 대신 글자로 같은 규칙을 시험하던 창이다. 🎙 음성 명령이 실기기에서 잘 돌아 더 쓸 일이 없다.

- 지운 것
  - 설정 → 앱 정보 "⌨️ 글자로 명령 시험" 토글 (TV 에도 보이던 줄)
  - ↑ 메뉴 · 연주자 메뉴의 ⌨️ 줄
  - 입력 창(`showVoiceTextInput` · `runTextCommand`)
- 정규화 · 규칙 · 명령 층은 그대로다 — 🎙 와 단위 테스트가 쓴다
- 저장돼 있던 `voice_text_input` 값은 읽는 곳이 없어 그냥 남는다

## 1. 지금 문제
1. **네 항목이 두 메뉴에 다 있다**: 메트로놈 설정 · 파트 보기 · 반주 · ✏️ 메모 쓰기. 메트로놈은 이름도 다르다("메트로놈 설정…" / "메트로놈 (실행 중)")
2. **"PDF 표시 옵션" 8줄 중 4줄이 표시 옵션이 아니다** — 위의 네 항목
3. **메모가 갈라져 있다**: 쓰기는 양쪽, 보이기는 PDF 표시 옵션에만
4. **예비박이 깊다**: 메트로놈 설정 → 박자 → 상세 안. 이것만 모든 파일 공통이고, 음성으로는 "예비박 한 마디"로 바로 바꾼다
5. **못 쓰는 줄이 보인다**
   - 태블릿 세로 · 휴대폰의 "두 페이지 모드" — 누르면 안내만
   - 지휘자의 "파트 보기" — 누르면 "총보만" 안내
6. **열리지 않는 대화상자**: 가운데 여백 · 사용자 정의 클리핑. 가운데 여백은 파일별 저장값대로 그려지는데 바꿀 길이 없다

## 2. 원칙
- 두 메뉴를 **목적으로** 나눈다
  - **↑ = 연주**: 소리와 시간 — 시작 · 멈춤 · 🎤 듣기 · 메트로놈 · 반주
  - **길게 = 보기**: 화면에 무엇을 어떻게 — 파트 · 마디 박스 · 메모 · 쪽 배치 · 자르기
- **한 항목은 한 메뉴에만**
- 그 기기 · 역할에서 **못 쓰는 줄은 숨긴다** — 누르면 안내만 뜨는 줄을 없앤다
- **여는 법은 그대로**(↑ · 두 번 탭 / OK 길게 · 길게 누르기). 손에 익은 것을 바꾸지 않는다

## 3. 정리안

```
↑ · 두 번 탭 → 연주                     OK 길게 · 길게 누르기 → 보기
────────────────────────────            ────────────────────────────
🎤 연주 듣고 넘기기     (태블릿·휴대폰)     파트 보기: 첼로          (지휘자는 숨김)
시작 — 악보에서 마디 고르기   (상태 줄)     마디 박스: 켜짐
메트로놈 설정…                           메모 보이기: 켜짐
반주: 켜짐 · 60%       (MusicXML)        ✏️ 메모 쓰기             (태블릿·휴대폰)
                                        두 쪽 보기: 자동         (TV 가로만)
                                        자르기 · 여백…
```

### ↑ 연주 (제목 "연주", 일시정지면 "연주 — 일시정지")
| 줄 | 보일 때 | 지금과 다른 점 |
|---|---|---|
| 🎤 연주 듣고 넘기기 · N마디부터 · 듣기 멈춤 | 태블릿 · 휴대폰 | 그대로 맨 위 |
| 상태 줄 (시작 / 정지 / 이어서 · 마디 골라 다시 · 정지 / ▶ N마디부터 · 고르기 취소) | 늘 | 그대로 |
| 메트로놈 설정… | 늘 | 여기에만 |
| 반주: 켜짐 · n% | MusicXML 이 있을 때 | 여기에만 |

빠지는 것: 파트 보기 · ✏️ 메모 쓰기 → 보기.

### 연주자 ↑ (합주 연주자)
| 줄 | 지금과 다른 점 |
|---|---|
| 이 기기만 빠지기 / 지휘자 연주에 다시 합류 | 그대로 |
| 메트로놈 소리: 끔 (누르면 켬 ↔ 끔) | 하위 대화상자 없이 바로 바뀜 |

빠지는 것: 파트 보기 · 메모 → 보기. 연주자도 길게 누르면 보기 메뉴가 뜬다.

### 보기 (제목 "보기" — 지금 "PDF 표시 옵션")
| 줄 | 보일 때 | 지금과 다른 점 |
|---|---|---|
| 파트 보기: (지금 파트 · 전체 악보) | 지휘자가 아닐 때 | 여기에만, 지휘자는 숨김 |
| 마디 박스: 켜짐/꺼짐 | 늘 | 이름 줄임 |
| 메모 보이기: 켜짐/꺼짐 | 늘 | 그대로 |
| ✏️ 메모 쓰기 / 메모 끝 | 태블릿 · 휴대폰 | 여기에만, 보이기와 붙여 둠 |
| 두 쪽 보기: 자동 · 두 쪽 · 한 쪽 | TV 가로만 | 터치 기기에서는 숨김, 지금 값 표시 |
| 자르기 · 여백… | 늘 (여백 줄은 두 쪽일 때만) | 클리핑 대화상자에 가운데 여백을 합침 — 결정 1 |

### 메트로놈 설정 대화상자
- **예비박을 첫 화면 넷째 줄로**: "예비박 [한 마디] [두 마디] · 모든 파일 공통". 박자 상세에서는 뺀다
- 나머지(박자 · 속도 · 소리 크기 · 구간)는 그대로
