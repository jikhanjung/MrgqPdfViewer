## 1. 탭 (사용자 결정: 탭 세 개 먼저, 앙상블별 줄은 나중)

| 탭 | 파일 |
|---|---|
| 전체 | 모두 |
| 이 기기 | `PDFs/` 바로 아래 — 웹 업로드 · 합주 중 지휘자에게서 받은 파일 |
| ☁️ ScoreMate | `PDFs/ScoreMate/*/` — 서버 동기화 |

- 헤더 아래 한 줄. 탭 모양(글자 + 선택된 탭 밑줄)이지만 **일반 버튼**으로 — Material `TabLayout` 은 TV 에서 포커스 표시 · 포커스와 선택이 따로 노는 문제가 있어
  기존 정렬 버튼과 같은 방식으로 리모컨 동작을 확실하게 했다 (`drawable/source_tab_background.xml`)
- **포커스만 옮겨도 탭이 바뀐다**(Google TV 홈처럼). 단 리모컨 키를 누른 뒤 500ms 안의 포커스 이동만 — 앱을 켜거나 악보에서 돌아올 때 포커스가 저절로
  탭에 놓여도 기억한 탭이 바뀌지 않게 (`dispatchKeyEvent` 로 마지막 키 시각)
- 탭 이름에 개수. 마지막 탭을 기억(`file_source_tab`). ScoreMate 에 연결하지 않았고 받은 악보도 없으면 ScoreMate 탭을 숨긴다
- 빈 탭 안내: ScoreMate 탭은 연결 여부에 따라 "설정 → ScoreMate → 지금 동기화" / "… 이 TV 를 연결하세요"
- 악보 화면의 이전/다음 파일은 **고른 탭 안에서**. 단 **연주자**는 전체 — 지휘자가 다른 탭의 파일로 바꿔도 악보 화면에서 찾게
- 합주 파일 찾기(`handleRemoteFileChange` · 요청 파일 · 받은 뒤 열기)는 탭과 상관없이 **전체**(`allPdfFiles`)에서

## 2. 합주로 받은 파일이 목록에 없던 문제 (버그)

연주자가 **악보를 보는 중** 지휘자가 없는 파일로 바꾸면 `PdfViewerActivity` 가 받는데, 공용 `Download/` 폴더에 썼다 — v0.1.8 에서
"앱 전용 폴더만" 으로 바꿀 때 빠진 경로. 그 자리에서는 열리지만 **파일 목록 어느 탭에도 나오지 않고** 다음에 또 받았다(Android 11+ 에서는 쓰기 자체가 막힐 수도).
→ `PDFs/` 바로 아래("이 기기")에 `.part` 로 받은 뒤 이름을 바꾼다. 쓸모없던 MediaScanner 호출도 뺐다. 파일 목록 화면에서 받는 경로는 원래 `PDFs/` 였다.

## 3. 남은 것

- ScoreMate 탭 안 앙상블별 줄 (`[모두] [현악 4중주] [내 악보]`)
- 합주로 받은 파일과 나중에 ScoreMate 로 받은 같은 악보가 두 벌이 되는 문제 → C4 `file_change.score_id` (연결된 연주자는 서버 악보를 바로 쓴다)
- 켜 둔 TV 의 주기적 동기화, 파일 목록에서 바로 동기화 (C3 나머지)
