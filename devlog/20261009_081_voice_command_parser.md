# 081 — 음성 명령 1단계: 정규화 · 규칙 처리기 (v0.6.4-beta.1)

## 무엇
`voice/` 패키지 — 순수 Kotlin(Android 의존 없음), JVM 단위 테스트 25개(발화 약 100개). 아직 어디에서도 부르지 않는다(화면 · 동작 변화 없음).

| 파일 | 하는 일 |
|---|---|
| `KoreanNumbers` | 한자어 · 고유어 수. 앞에서부터 욕심껏 읽되 자릿값이 내려갈 때만 한 수 — "칠십이오십칠" = 72, 57. 둘이 같은 길이면 한자어 |
| `VoiceLexicon` | 낱말 표(`Kw`) · 서수 · 악기 별칭 21종 · 알파벳 읽기 · 조사 · STT 오인식 고침 |
| `CommandNormalizer` | STT 글자 → 조각(`Token`). 공백을 지우고 읽고(아라비아 숫자 사이 공백만 경계), 한 자리에서 어휘(긴 것부터) → 아라비아 숫자 → 한국어 수 |
| `VoiceCommand` · `ParseResult` | 명령 종류, 결과 = 명령들 / 수만 들림 / 못 알아들음(이유). 표시 문구 "57마디 · ♩=72"(위치 먼저), 실행 순서는 템포 · 파트 → 위치 → 시작 |
| `CommandParser` | 규칙: 수는 바로 뒤 단위에 붙는다(번 · 번째는 건너뜀), "다시"는 다른 위치에 양보, "시작"은 재생을 시작하는 위치가 있으면 빠짐 |

## 계획 표(P12 §3)에 없던 판단
- **한 글자 수는 앞뒤를 보고**: "오 · 세 · 열 · 백"은 바로 뒤가 마디 · 쪽 · 번째 · bpm 이거나 앞이 템포 · 악기일 때만 수 — "세게", "일시정지", "한 번 더"가 수가 되지 않게
- **"이 마디부터"는 받지 않는다**: 2 인지 "지금 이 마디"인지 모름. "이"는 악기 뒤("바이올린 이" = 2)에서만 수
- **상대 위치 거절**: "전 · 뒤 · 후", 쪽 앞이 아닌 "앞"("57마디 앞") → `RELATIVE`. 두 마디 전을 2마디로 가지 않게
- **"장" = 쪽, 단 "악장" · "장조"는 막는 낱말**(`BLOCK`) — "2악장 57마디"는 붙을 데 없는 2 가 남아 `STRAY_NUMBER`
- **레터 뒤 한 글자는 알파벳**("레터 이" = E), 수면 그 번호("리허설 삼십" = 30)
- 서수가 악기 앞("세컨 바이올린")도, 뒤("비올라 둘째")도
- 수 하나만("칠십이요") → `BareNumber` — 마디인지 템포인지는 실행하는 쪽이 지금 화면으로 정한다(P12 §3.2)
