# 120 — 업데이트 요청에 기기 정보 (서버가 어느 기기가 받았는지 기록)

2026-10-11 · [P15](20261010_P15_private_repo_releases_on_scoremate_plan.md) 3단계 보조 · 사용자: "어떤 기기에서 다운로드 받았는지 알 수 있어?" → "응 진행해줘"

## 왜
v0.7.6 까지 앱은 업데이트 확인 · 받기 때 기기 정보를 하나도 보내지 않았다(User-Agent 고정 `MrgqPdfViewer-updater`, 토큰 없음). 집 기기들은 공인 IP 도 같아 서버에서는 어느 기기가 받았는지 알 수 없다.
P15 3단계("모든 기기 ≥ v0.7.6")를 기기마다 설정 → 앱 정보를 열지 않고 서버에서 한눈에 보려고.

## 바꾼 것 — ScoreMate 서버로 가는 요청에만
- `latest/?channel=…`(10분마다 자동 · 수동 확인)와 받기 주소(`<version>/apk/`)의 **첫 요청**에 붙인다:
  - `User-Agent: MrgqPdfViewer/<앱 버전> (<tv|tablet|phone>; <제조사 모델>; Android <버전>)`
  - `X-Mrgq-Install: <UUID>` — 설치마다 무작위(`scoremate` prefs `install_id`, 백업 제외 · 연결을 끊어도 남김). 연결 안 한 기기 · 같은 모델 두 대(Z18TV × 2)를 가른다
  - `X-ScoreMate-Device: <device_id>` — ScoreMate 에 연결돼 있으면 연결 때 받은 값(서버가 기기 이름과 맞춘다)
- 받기 주소의 302 는 앱이 직접 한 번 따라가고, 서명 URL(저장소)에는 기기 정보를 붙이지 않는다
- **토큰은 보내지 않는다** — 인증이 아니라 기록이다. 만료된 토큰이면 401 이 나 업데이트 확인이 막힐 수 있다
- 머리글 값은 ASCII 만(한글 · 괄호 · 쌍반점은 공백으로) — 아니면 연결이 예외로 끝난다. 기기 정보를 못 만들면 붙이지 않고 업데이트는 그대로
- GitHub 경로(폴백)에는 지금처럼 고정 User-Agent 만
- `update/UpdateDevice`(JVM 테스트), `UpdateController.updateDevice`, `UpdateClient(device = …)`

## 서버 (서버 세션, 2026-10-11 요청 · 수락)
- install 하나에 한 줄(check 때마다 마지막 확인 · 앱 버전 · 채널 갱신), download 는 요청마다 한 줄. 웹 `/apk/` 짧은 주소로 받은 것(머리글 없음)도 download 로
- 머리글이 없거나 깨져도 응답은 그대로 — 기록만 빈다. 응답 필드는 그대로
- 관리자 화면 **`/manage/app-installs/`**(관리자만)에 기기 목록(이름 또는 모델 · 종류 · 앱 버전 · 마지막 확인 · 마지막 받은 판). "?" 로 온 값은 빈 칸
- 구현 · 테스트 완료(2026-10-11), 운영 배포는 사용자 확인 뒤
