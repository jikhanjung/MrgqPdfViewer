# 127 — 설정은 제목만(설명 줄 뺌 · 제목 줄임) · 웹서버는 그 칸을 떠나면 멈춤

2026-10-12 · 사용자: "웹서버는 웹서버 설정 화면을 빠져나오면 종료하는 게 좋겠어." · "영어로 잘 나오는데 특히 설정 항목들에서 제목과 설명이 있는 경우 제목이 길어져서 줄바꿈이 꽤 많이 일어나. 설정의 제목들에 설명이 들어가는 건 꼭 필요하지는 않은 것 같아. 한 번 제목만 남기고 설명은 모두 제거해봐. 그리고 제목은 가능하면 짧게 쓰는 게 좋겠고."

## 설정 — 제목만
- `SettingsItem.subtitle` 을 **없앴다**(줄 레이아웃 셋의 `subtitleText` 도) — 설명이 다시 붙을 자리가 없다. 왼쪽 카테고리의 요약 줄(파일 수 · 웹서버 상태 · 연결 상태 · 버전 등)도 뺐다
- 대신 **지금 값은 줄 오른쪽에**(`SettingsItem.value`, ▶ 자리 — 한 줄, 260dp 넘으면 끝을 줄임): 웹서버 주소(켰을 때) · 포트 · 넘김 지연 · 입력 차단 ms · 메시지 큐 꺼짐 · 연결된 기기 이름 · 서버 · 소리 크기 · 회전 · 언어 · 버전 · 음성 언어 · 호출어 · 녹음(날짜 · 길이) · 모두 지우기(MB). 켜기 · 끄기는 스위치가 값(TV 도, #122)
- 설명만 하던 줄은 뺐다: 합주 모드 안내, 웹서버 활동 로그 안내(로그 칸은 그대로 아래에), 앱 정보 묶음(앱 소개 한 줄), 녹음 저장 위치. 녹음 줄의 시작 마디 · 넘김 수는 눌러서 여는 대화상자에만
- 🎙 음성 인식 서비스가 없는 기기: 오른쪽 값 "설치 필요", 누르면 전처럼 설치 안내
- 웹서버 줄은 "웹서버 시작 / 중지" 단추 글 → **"웹서버" 스위치**
- 제목 줄임(한 · 영): 협업 모드 → 합주 / Ensemble · 녹음 기록 → 녹음 · 표시 모드 → 표시 / Display · File management → Files · 모든 PDF 파일 삭제 → PDF 모두 삭제 · 포트 설정 → 포트 · 합주 메트로놈 소리 (연주자) → 연주자 메트로놈 소리 / Performer metronome · 동기 페이지 넘김 → 동기 넘김 · 예약 시간 → 넘김 지연 · 입력 차단 시간 → 입력 차단 · 메시지 큐 통계 → 메시지 큐 · 서버 주소 → 서버 · 페이지 전환 애니메이션 → 넘김 애니메이션 · 페이지 넘기기 사운드 → 넘김 소리 · 사운드 볼륨 → 소리 크기 · 페이지 정보 표시 → 페이지 정보 · 회전 모드 (악보 화면) → 회전 · 설정 목록 보기 → 파일별 설정 · 설정 초기화 → 모두 초기화 · 앱 버전 → 버전 · 자동 업데이트 확인 → 자동 확인 · 사전 릴리스(beta) 받기 → 베타 받기 · 계속 듣기 (시험) → 계속 듣기(묶음 제목은 "(시험)" 그대로) · 호출어 (계속 듣기) → 호출어 · 음성 명령 언어 → 음성 언어 · 녹음이 없습니다 → 녹음 없음. 동기 넘김 묶음 제목은 "시험 기능"
- 값 글도 짧게: 언어 "시스템 따름 — 한국어" → "시스템 (한국어)", 음성 언어 "앱 언어 따름 (지금 한국어)" → "앱 언어 (한국어)"
- 쓰지 않게 된 글 키 71개를 `values` · `values-en` 에서 지웠다(772키)
- 설명이 할 일은 설명서가 맡는다(P19 §4 "설정 한눈에")

## 웹서버 — 그 칸을 떠나면 멈춤
- 전: 한 칸(휴대폰)은 웹서버 칸을 나갈 때 **물었고**, 두 칸(TV · 넓은 태블릿)은 다른 칸으로 옮겨도 돌다가 설정을 나갈 때 물었다(#106)
- 지금: **웹서버 칸을 떠나면 묻지 않고 멈춘다** — 다른 카테고리로(두 칸은 TV 왼쪽 포커스 미리 보기도), 한 칸에서 목록으로, 설정을 나갈 때. 토스트 "웹서버가 중지되었습니다". 확인 대화상자 둘(`showWebServerExitConfirmDialog` · `showWebServerDetailExitConfirmDialog`)은 지웠다
- 같은 칸 안의 다시 그리기(스위치 · 포트 바꾸기)에서는 멈추지 않는다 — `showDetailPanel` 이 칸 id 가 바뀔 때만 `stopWebServerNow()`
- 화면이 꺼지거나 홈으로 나가는 것(onPause)은 그대로 둔다 — 올리는 중에 TV 화면 보호기가 떠도 끊기지 않게. 설정이 끝나면(onDestroy) 전처럼 멈춘다
