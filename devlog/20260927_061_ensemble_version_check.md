## 0. 왜 (사용자 요청)

합주 메시지에 버전마다 필드가 늘었다 — 옛 연주자는 `tempo_sections` · `count_in_bars` 를 몰라 첫 구간 템포 · 한 마디 예비박으로 센다 →
**박 · 마디가 조용히 어긋난다.** 연결할 때 서로 버전을 확인하고 다르면 양쪽 화면에 "버전을 맞추세요" 를 띄운다.

## 1. 동작

- 연주자 → `client_connect.app_version` = 실제 앱 버전(`BuildConfig.VERSION_NAME`). v0.2.5 까지는 **"v0.1.5" 고정**이었다
- 지휘자 → `connect_response.app_version` = 실제 버전 (옛 호환용 `server_version: "v0.1.5"` 는 그대로 둔다)
- 비교(`ensemble/EnsembleVersion`): 같으면 조용히. 상대가 "v0.1.5" 이거나 값이 없으면 **"v0.2.5 이하"**(옛 버전)로 본다. 다르면 어느 쪽이 옛 버전인지 가려
  업데이트할 기기를 가리킨다 — 예) 연주자 화면 "지휘자 기기가 v0.2.5 이하입니다 (이 기기 v0.2.6). 지휘자 기기를 v0.2.6 으로 업데이트하세요."
  지휘자 화면 "연주자 '거실 TV' 이(가) v0.2.5 이하입니다 …". 끝에 이유(박 · 마디 · 예비박 어긋남)와 업데이트 위치(설정 → 앱 정보 → 업데이트 확인)
- **정확한 버전 비교**(패치까지): 합주 메시지가 패치 버전마다 바뀌어 왔으므로 기능 단위 구분 없이 같은 버전을 요구한다
- 표시: 앞에 있는 화면(파일 목록 · 악보 · 설정)이 대화상자로 (`ensemble/VersionNotice`, onResume 등록 · onPause 해제). 앞 화면이 없으면 토스트.
  같은 안내는 앱을 켜 둔 동안 한 번만(재연결마다 다시 뜨지 않게)

## 2. 한계

- **옛 연주자(v0.2.5 이하)는 안내를 못 띄운다** — 새 필드를 모른다. 대신 새 지휘자가 그 연주자를 알아보고 지휘자 화면에 알린다.
  반대로 옛 지휘자에 새 연주자가 붙으면 연주자 화면에 뜬다. 둘 다 옛 버전이면 아무도 모른다(지금과 같음)
- 연결을 막지는 않는다 — 페이지 넘김 같은 기본 합주는 버전이 달라도 된다

## 3. 테스트

`EnsembleVersionTest` 4개: 같은 버전 · `v` 접두 무시, 옛 버전("v0.1.5" · 없음), 어느 쪽이 옛 버전인지, 안내문이 업데이트할 기기를 가리키는지
