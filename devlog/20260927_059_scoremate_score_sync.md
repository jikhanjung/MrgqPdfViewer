## 0. 요약

연결된 TV 는 앱을 켤 때(heartbeat 뒤) · 설정 → ScoreMate → "지금 동기화" 로 악보를 받는다.
받은 악보는 **`PDFs/ScoreMate/<앙상블 | 내 악보>/<제목>[ (파트)].pdf`** (사용자 결정: 하위 폴더), 파일 목록에 `☁️ 앙상블 · 파트 · 판 n`.

## 1. 동기화 (`scoremate/ScoreMateSync`)

1. 커서부터 `has_more` 가 끝날 때까지 쪽을 모두 받는다. 400 `{"cursor"}` → 커서를 버리고 처음부터 한 번
2. 받은 악보마다: sha256 이 null(서버 처리 중) → 건너뜀. 가진 판과 sha 가 같고 파일이 있으면 그대로(경로만 달라졌으면 옮김).
   다르면 받기: `download_url` → **302 를 직접 따라가 서명 URL 은 인증 없이** → `<파일>.part` → **SHA-256 검증** → 교체
3. 서버 `ids` 에 없는 악보 → 파일 · 레코드 삭제. **안전장치**: `ids` 가 비었거나 max(2, 가진 수/2) 보다 많이 사라지면 지우지 않고
   "n개를 지울까요?" 를 묻는다(확인하면 `allowLargeRemoval`)
4. **모두 성공했을 때만 커서를 저장**한다 — 받기 하나라도 실패하면 다음에 같은 자리부터(이미 받은 것은 sha 가 같아 건너뜀)

- 호스트는 늘 설정한 서버 — `download_url` 의 절대 URL 에서 경로만 쓴다
- 동기화는 파일 목록 화면(앱 시작)과 설정에서만 — 악보를 보는 중 · 합주 중에는 돌지 않아 열린 파일을 바꾸지 않는다

## 2. 이름 규칙 (`ScoreMateNaming`, P05 §6)

- 금지 문자 `/ \ : * ? " < > |`·제어 문자 → `_`, 공백 정리, 앞뒤 점 제거, 80자
- 같은 폴더에 같은 이름이 둘 이상이면 **모두** ` [#<서버 id>]` — 어느 TV 에서나 같다. 하나가 사라지면 남은 것은 원래 이름으로 옮긴다
- 그 자리에 우리 것이 아닌 파일이 있으면 ` [#id]` — 단, **내용(SHA-256)이 이 악보 판과 같으면 우리 것으로 보고 받지 않는다**
  (연결 해제 때 남긴 파일을 다시 연결하면 그대로 쓴다. 로컬 테스트에서 두 번째 사본을 받던 버그를 잡음)
- 앙상블 폴더 이름은 앙상블 id 마다 하나(이번에 받은 이름 우선) — 서버가 앙상블 이름 변경 때 악보 `updated_at` 을 올리지 않아서(P06 §1)

## 3. 파일별 설정 유지 (P05 §6)

`pdf_files` 는 **경로로** 레코드를 찾는다(`PdfFileSync`). 옮길 때는 `LocalPdfRecords.beforeMove` 로 레코드의 `filePath` · `filename` 을
먼저 update(`PdfFileDao.movePath`)한 뒤 파일을 옮긴다 → 두 페이지 · 클리핑 · 메트로놈 · 구간 설정이 따라간다.
같은 경로에 새 판을 덮어쓰면 레코드는 그대로이고 `PdfFileSync` 가 바뀐 파일로 보고 다시 분석한다(설정 보존).

## 4. DB v14 — `server_scores`

`serverId` PK · `filePath` · 판 번호 · sha256 · 제목 · 작곡가 · 파트 · 앙상블 id/이름 · `hidden` · `syncedAt`. 새 테이블만 더하는 마이그레이션.
P05 는 `scoremate_state` 테이블에 커서를 두려 했으나 **prefs(`scoremate`)의 `sync_cursor`** 로 — 연결을 끊으면 토큰과 함께 지워진다.

## 5. 숨김 · 연결 해제

- 파일 목록에서 ☁️ 악보를 지우면 `hidden` — 다시 받지 않는다(새 판이 와도). 설정 → "숨긴 악보 다시 받기" 가 숨김을 풀고 커서를 처음으로
- 연결 해제: "해제 · 악보 남기기"(보통 파일로 남는다) / "해제 · 악보 지우기"
- 웹 업로드 목록 · 설정의 "PDF 전체 삭제" · 파일 개수는 **`PDFs/` 바로 아래 파일만** — 서버 악보는 동기화가 관리한다

## 6. 파일 목록 (`PdfLibrary`)

`PDFs/` 바로 아래 + `PDFs/ScoreMate/*/` 아래 PDF. 그 밖의 하위 폴더와 `.part` 는 보지 않는다.
합주 파일 전달은 파일 경로를 등록해 보내므로(`FileServerManager.addFile`) 하위 폴더 파일도 그대로 된다. 연주자 쪽 파일 찾기는 여전히 **이름**으로 —
`score_id` 로 찾기는 C4.
