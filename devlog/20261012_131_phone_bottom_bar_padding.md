# 131 — 휴대폰 세로: 아래 막대 "✏️ 메모" 가 두 줄이 되던 것

2026-10-12 · 사용자: "폰에서 악보 탭했을 때 연주 보기 메모 메뉴가 나오는데 메모에서만 아이콘과 텍스트 사이에 줄바꿈이 일어나." · "아 세로 화면일 때" · "그 각 메뉴들의 폭을 조금씩만 줄이면 될 것 같아."

## 원인
- 아래 막대(`viewerBottomBar`)는 오른쪽 🎙 자리로 `paddingEnd` 96dp 를 비운다 — 휴대폰 세로(약 411dp)에서 남는 폭은 300dp 남짓
- 단추마다 양옆 16dp 여백 + 18sp 글이라 셋이 거의 꽉 차고, 마지막 "✏️ 메모" 가 눌려 이모지 뒤에서 줄이 바뀌었다(쪽 글은 세로에서 막대에 서지 않는다 — 가로만)

## 바꾼 것
- 휴대폰은 단추 양옆 여백 16 → **10dp**(태블릿은 그대로). 세 단추 합이 한국어 약 250dp · 영어("✏️ Annotate") 약 290dp 로 들어간다
- 단추 글은 **한 줄**(`maxLines = 1`) — 그래도 넘치면 줄바꿈 대신 끝을 줄인다
