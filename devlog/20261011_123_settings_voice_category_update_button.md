# 123 — 설정: 🎙 음성 명령을 맨 위 칸으로, "업데이트 확인"을 단추로

2026-10-11 · [#122](20261011_122_settings_detail_android_style.md) 뒤 · 사용자: "음성명령은 앱 정보 말고 설정 탑 레벨로 빼는 게 좋겠어. 계속 듣기랑 묶어서 별도의 탑 메뉴가 있어야 할 것 같네. 업데이트 확인이 자동 업데이트 확인보다 위로 가는 게 좋을 것 같고, 그게 버튼인지 아닌지 눈에 잘 안 띄어. 버튼이라는 걸 분명히 알 수 있게 만들어줘."

## 바꾼 것
- 왼쪽 카테고리에 **🎙 음성 명령**(태블릿 · 휴대폰만 — TV 는 음성 명령이 없다) — ScoreMate 와 녹음 기록 사이. 설명은 "누르고 말하기 · 계속 듣기"
  - 칸 안: 묶음 "누르고 말하기"(🎙 음성 명령 켜기) · "계속 듣기 (시험)"(👂 계속 듣기, 🗣 호출어 — 호출어는 계속 듣기를 다시 쓸 수 있을 때만)
  - 앱 정보에서는 뺐다. 켜기 · 끄기 · 호출어 저장 뒤에는 이 칸을 다시 그린다(`showVoicePanel`)
- 앱 정보: 업데이트 묶음 순서 = 앱 버전 → **업데이트 확인** → 자동 업데이트 확인 → 사전 릴리스 받기
- **단추 줄**(`SettingsType.BUTTON`, `item_settings_button` · `settings_button_background`): 채운 파랑 둥근 단추에 제목, 설명은 단추 아래. 리모컨 포커스면 단추가 밝아지고 흰 테두리, 누르면 진하게. 오른쪽(상세) 목록에서만 — 지금은 "업데이트 확인" 하나
- 문서: `docs/Voice_Commands.md` · `docs/Viewer_Menus.md` 의 "설정 → 앱 정보 → 🎙" 를 "설정 → 🎙 음성 명령"으로

## 확인
- [ ] 태블릿 · 휴대폰: 설정 왼쪽에 🎙 음성 명령, 켜기 · 끄기 뒤 그 칸 그대로
- [ ] TV · 태블릿: 앱 정보의 "업데이트 확인"이 단추로 보이고, 리모컨 포커스가 단추에 보인다. TV 에는 🎙 칸이 없다
