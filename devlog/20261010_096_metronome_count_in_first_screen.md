# 096 — 예비박을 메트로놈 설정 첫 화면으로 (P13 2단계)

2026-10-10 · P13 · 사용자: "3단계까지 모두 끝내고 보자."

## 바꾼 것
- 메트로놈 설정 대화상자(`buildMetronomeDialog`) 첫 화면, 소리 크기 아래에 **"예비박: n마디 — 악보에서 마디를 골라 시작할 때"** 줄과 [한 마디] [두 마디] 단추를 넣었다. 고른 쪽에 ✓
- 박자 → 상세에서는 예비박을 뺐다
- 값 · 저장은 그대로다: 전역 `metronome_count_in_bars`(#060). 음성 "예비박 한 마디"와 같은 값이다
- 첫 화면 안내: "템포 · 박자는 이 파일에, 소리 · 예비박은 모든 파일에 저장됩니다"

## 왜
예비박만 모든 파일 공통이고 자주 바꾼다. 그런데 파일별 박자 설정의 상세 안 깊은 곳에 있었다(P13 §1-4).
