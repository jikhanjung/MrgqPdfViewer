## 0. 사용자 결정

> 가장 간단한 방법은 로컬에만 있는 파일을 사용하지 않는 것. 서버와 연결되면 로컬 파일들은 못 쓰게. 다른 계정이고 동일한 score_id 가 없으면
> 그 파일을 받되 캐시만. 연결되면 웹서버 기능은 disable. 캐시 파일 설정도 저장.

어디서 온 파일인지 사람이 따질 필요가 없고, 같은 악보가 두 벌 생기지 않는다. #062 의 탭(전체 · 이 기기 · ScoreMate)은 필요 없어져 걷어냈다.

## 1. 서재

| TV | 파일 목록 | 웹서버 |
|---|---|---|
| ScoreMate 연결됨 | `PDFs/ScoreMate/*/` 만 (`☁️ ScoreMate 악보 n`, "☁️ 동기화" 버튼) | **끔** — 설정에 "ScoreMate 에 연결된 TV 에서는 쓸 수 없습니다". 연결하는 순간 실행 중이면 멈춘다 |
| 연결 안 됨 | `PDFs/` 바로 아래만 (`이 기기 파일 n`) | 지금과 같음 |

- 반대쪽 파일은 **지우지 않는다** — 보이지 않을 뿐. 연결을 끊으면 로컬 파일이 다시 보인다
- 연결 해제 "악보 남기기" → 받은 악보를 **`PDFs/` 로 옮긴다**(레코드 먼저 → 파일별 설정 유지, 이름이 겹치면 ` (2)`) — 해제 뒤 서재에 보이게. "지우기" 는 그대로

## 2. 합주 — 연주자가 지휘자 파일을 찾는 곳 (`ensemble/EnsembleFiles`)

지휘자는 `file_change` 에 연 파일 **내용의 SHA-256** 을 싣는다(파일 목록 · 악보 화면 · 새 연주자에게 현재 상태 보낼 때).
ScoreMate 악보는 받을 때 검증한 값, 로컬 파일은 한 번 계산해 기억한다(경로 · 크기 · 수정 시각이 같으면 다시 계산하지 않음).

**왜 `score_id` 가 아니라 SHA-256 인가** (처음엔 score_id 로 구현했다가 바꿈 — 사용자 질문 "score_id 는 전역이야?"):
`score_id` 는 서버 DB 의 자동 증가 번호(`BigAutoField`)라 **서버마다 따로** 매긴다(개발 서버 · 운영 서버에서 같은 번호가 다른 악보).
또 **판이 달라도 같은 번호**라, 지휘자가 판 2 를 볼 때 아직 동기화하지 않은 연주자가 판 1 을 열면 페이지 · 마디가 어긋난다.
내용 해시는 서버 · 계정과 상관없고 판까지 맞는다 — 다른 계정이라도 같은 파일을 가졌으면 그것을 쓴다.
(MD5 가 아니라 SHA-256: 서버 `content_hash` · 받기 검증과 같은 값이라 ScoreMate 악보는 계산이 필요 없고, MD5 는 일부러 같은 해시의 다른 파일을 만들 수 있다)

| 연주자 | 찾기 | 없으면 |
|---|---|---|
| 연결됨 | ① **같은 내용**이 내 ScoreMate 에(숨기지 않고 파일 있음 — 이름 · 계정 무관) ② 캐시(`cacheDir/ensemble/<해시 앞 16자>/<이름>`) | **캐시로 받는다** — 목록에 없음. "합주용으로만 받아 두고 목록에는 넣지 않습니다" |
| 연결 안 됨 | 서재(`PDFs/`)에서 이름 | `PDFs/` 로 받는다 (지금과 같음) |

- 내 ScoreMate 에 없는 악보 · 판이 다른 악보 · 숨긴 악보 · 지휘자의 로컬 파일 → 캐시. 지난 합주에 받은 캐시가 있으면 다시 받지 않는다
- 지휘자가 해시를 보내지 않으면(v0.2.6 이하) 이름으로 (`cacheDir/ensemble/<이름>`)
- **캐시 파일도 설정이 저장된다** — 경로가 내용마다 일정해 `pdf_files` 레코드(두 페이지 · 클리핑 · 메트로놈 · 구간)가 그대로 이어진다.
  캐시가 지워졌다가 다시 받아도 같은 경로라 설정이 돌아온다
- 캐시 상한 200MB — 넘으면 오래 안 쓴(연 시각) 파일부터 지운다. 시스템이 공간이 모자라면 지울 수도 있다(설정은 DB 에 남는다)
- 찾은 파일이 지금 목록에 없으면(캐시) 목록 끝에 붙여 연다 — 이전/다음은 서재 안에서
- **보안**: 지휘자가 보낸 파일 이름을 경로로 그대로 쓰지 않는다 — `../` 등 디렉터리 부분을 버린다(`safeName`). 전에는 `File(폴더, 이름)` 이라
  `../` 로 앱 폴더 밖에 쓸 수 있었다
- 연결 안 된 TV 는 서재에서 이름으로만 찾는다 — 로컬 파일을 모두 해시하지 않으려고(연결 안 된 TV 는 지금까지와 같은 동작)

## 3. 호환

- `file_change.sha256` 은 선택 필드 — 옛 연주자는 무시하고 이름으로 찾는다. 형식(64자 hex)이 틀리면 버린다
- 연결 해제 시 파일을 옮기므로 v0.2.6 에서 "남기기" 로 해제한 경우(파일이 ScoreMate 폴더에 남음)는 다시 연결하면 그대로 보인다
