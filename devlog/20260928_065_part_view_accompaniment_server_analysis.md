## 2. 파트보 보기 (P07)

- **분석**: 시스템마다 보표 띠 · 이름을 저장(`score_staves`, DB v15). 파트 = 보표 순번, 시스템마다 보표 수가 같을 때만(`ScoreParts`). 보표 이름은 보표 왼쪽 텍스트(`StaffLabelDetector`) — Sibelius → Microsoft Print to PDF 는 글자로 읽히지 않아 "보표 n", 그때는 MusicXML 파트 이름으로 채운다
- **렌더 = 파트 PDF**: 고른 보표만 잘라 세로 A4(원본 쪽 크기, 1:1)로 쌓은 **벡터 PDF** 를 앱 캐시에 만든다(`PartLayout` · `PartPdfBuilder` — PdfBox 폼 + clip + translate). 뷰어는 원본 대신 이것을 연다 → 두 쪽 모드 · 캐시 · 넘김 애니메이션이 그대로. 파일 이름 · 파일 ID 는 원본 그대로(설정 · 합주 · 분석은 원본 기준). 기기 안에만 둔다(저작권 원칙, P07 §0)
- **자르기**: 이웃 보표와의 가운데 + **소속에 따라 넓히기**(`PartClip`) — 가운데선을 걸친 경로는 가운데가 있는 쪽 보표 것, 덧줄 기둥은 끝 덧줄 너머 음표 머리까지. 몰다우에서 걸친 그림 415 · 넘는 덧줄 음 11(39쪽 7pt)을 PyMuPDF 로 세고 시작했다. 슬러는 아직 일부 잘린다(사용자: 괜찮다)
- **여러 파트**: 이웃한 보표는 한 조각, 떨어진 보표는 시스템마다 붙여 같은 쪽에. 보표 앞 `Pt. n`, 마디 · 쪽 번호는 첫째 · 둘째 보표 사이. 선택은 보표 비트 마스크(DB v17)
- **번호**: 줄마다 원본 마디 번호 · 원본 쪽(`p.7`), 화면 쪽 정보에 "총보 n~m쪽". 왼쪽 쪽(짝수)만 위 여백 64pt — 박 표시 아래에서 시작
- **마디 연동**: `PartLayout.mapMeasures` 로 원본 마디를 파트 PDF 좌표로 옮겨 넘기면 마디 박스 · 악보 연동이 코드 변경 없이 돈다
- **합주**: 주고받는 쪽 번호는 늘 원본 쪽(`sourcePageFor` · `dstPageForSource`), 마디 신호는 그대로

## 3. MusicXML 반주 (P07 5 · 6단계)

- ScoreMate 가 PDF 옆에 둔 `.musicxml`(P06 §11)을 `MusicXmlReader`(javax.xml DOM)로 — 화음 · 붙임줄 · 성부 · 꾸밈음. 마디 수 · 박자가 악보와 같아야 켠다(`MusicXmlMatch`)
- 음을 **박 위치**(소수)로 놓고(`ScoreFollower.beatAt`) 메트로놈 오디오 루프가 박 k ~ k+1 사이에 샘플 단위로 켠다 → 빠르기 · 구간별 빠르기 · 예비박 · 이어서를 그대로 따른다. 단순 합성(`AccompanimentVoices`), 파트마다 음색
- 파트 보기면 내 파트 빼고, 전체 악보면 모두. 반주 크기는 클릭과 따로. 합주 중에는 끈다

## 4. 서버와 함께 (P06)

- **MusicXML 동기화** (§11): PDF 옆 곁 파일, sha 다를 때만, null 이면 지움, PDF 따라 옮김/지움. **앱 동기화 형식**(`sync_format`)이 오르면 커서를 한 번 처음부터 — 옛 앱이 지나간 변경의 새 필드를 놓치지 않게(실제로 K488 에서 겪었다)
- **서버 분석 파일** (§12): 서버가 앱 `score/` 를 파이썬으로 옮겨 판마다 돌린다. TV 는 `.layout.json` 을 받아 `pdf_sha256` 이 맞으면 `ScoreLayout` 으로 읽어 쓴다(`ServerLayouts`), 파일이 캐시보다 새로우면 다시 읽는다 — DB 마이그레이션으로 캐시를 비우던 것을 대신. K488 99 · Moldau 268 마디가 앱 분석과 같았다
- **곡 정보** (§10): `arranger` 를 읽어(DB v18) 목록 둘째 줄 "작곡 · 편곡". 곡 정보만 바뀌어도 `SyncReport.updated` 로 목록을 다시 그린다(편곡자가 저장돼도 화면이 안 바뀌던 것)
- 파트 이름 오인식(K488 "예원" → "예완")은 서버에서 고치면 MusicXML sha 가 바뀌어 TV 가 새로 받는다(서버 0.9.8)

## 5. 앱 안 업데이트 · 운영
