# 111 — 녹음 재생이 들리지 않던 것: 기기 미디어 소리 0

2026-10-11 · 사용자: "타블렛에서 녹음 기록 플레이해도 들리질 않네."

## 원인 — 앱이 아니라 기기 소리 설정 (adb 로 확인)
- `dumpsys audio`: **STREAM_MUSIC 음량 0 · 음소거**(0 / 15). 벨 · 알림 · 시스템 소리도 꺼짐(무음 모드 — 방해 금지는 꺼짐)
- 녹음 재생(`MediaPlayer`, 기본 = 미디어)도, 메트로놈 · 반주(`AudioTrack`, `USAGE_MEDIA`)도 이 소리로 나므로 0 이면 들리지 않는다
- 앱이 소리를 끄는 곳은 👂 계속 듣기의 **알림** 소리 끄기(#092)뿐이고, 👂 는 꺼 두었다(#093) — 미디어 소리와 무관
- 녹음 파일 자체는 정상(아르페지오네 듣기 기록 8개, 4 ~ 84MB)

## 바꾼 것
- 녹음 재생을 누를 때 **미디어 소리가 0 이면 "미디어 소리가 0 이에요 — 볼륨 키(위)로 올리세요"**
- 설정 화면 · 악보 화면의 **볼륨 키 = 미디어 소리**(`volumeControlStream = STREAM_MUSIC`) — 아무것도 울리지 않을 때 볼륨 키를 누르면 벨소리가 바뀌던 것. 이제 재생 전에도 메트로놈 · 녹음 소리를 올릴 수 있다

## 확인
- [ ] 태블릿: 미디어 0 에서 재생 → 안내, 볼륨 키 위 → 들림. 악보 화면에서 볼륨 키가 미디어 음량 막대를 띄우는지
