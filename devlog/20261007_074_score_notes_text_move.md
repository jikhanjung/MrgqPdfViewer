## 2. 한 일
- 모델 `ScoreNote.Text`(id · 쪽 · 색 · 크기 pt · 왼 위 x, y · 글자 · 붙는 보표). 곁 파일 `{"type": "text", "color", "size", "x", "y", "text", "staff"}`
- **줄 배치를 정해 둠**(`TextLayout`) — 첫 줄 기준선 = y + 0.8 × size, 줄 간격 1.2 × size, `\n` 으로 줄 나눔. 서버 웹 겹쳐 보기가 같게 그리도록 서버 세션에 알림. 앱 글꼴은 기본 굵게
- **메모는 불변**(P11 §6): 고치기 · 옮기기 = `ScoreNotes.replace(old, new)` — 옛 id 지우고 새 id, 되돌리기 한 번. `movedBy(dx, dy, 새 id, 보표)`
- `NotePen`: 도구 `TEXT`(떼는 곳이 누른 곳에서 24px 안이면 탭) · `MOVE`(누른 곳 28px 안의 메모를 잡아, 누른 곳에서 끈 만큼 pt 로). 메모 모드 밖의 펜은 늘 펜
- 뷰어: 🅰 탭 → 입력 창(AlertDialog + EditText, 여러 줄, 키보드 바로) — 있는 글자면 고치기(비우거나 "지우기"면 지우기), 새 글자는 탭한 곳이 첫 줄 가운데 높이. ✋ 끄는 동안 옮긴 모습 · 점선 테두리 · 붙을 보표 표시, 놓으면 보표를 다시 정해 저장. 지우개가 글자도 지움
- 도구 줄: ✏️ 🧽 🅰 ✋ · 색 3 · 굵기 3(글자 도구면 글자 크기 8 · 11 · 15pt, 단추가 "가" 크기로 바뀜) · ↶ ↷ ✔
- 메모 맞히기는 나중에 그린 것(위에 보이는 것)부터
- 테스트: `ScoreNotesTest` +4(글자 왕복 · 바꿔 끼우기 · 획 옮기기 · 글자 상자) — "모르는 type 보존" 시험은 이제 아는 `text` 대신 `stamp` 로
