# 102 — 악보 화면 도구 막대 · 두 번 탭 없앰 (P17 2단계)

2026-10-11 · [P17](20261011_P17_touch_ui_shell_plan.md) 2단계 · 사용자: "계속 진행해줘"

태블릿 · 휴대폰(`touchShell()` — TV 가 아님)만. TV 는 리모컨 그대로.

## 바꾼 것
- **도구 막대**(`activity_pdf_viewer.xml` 의 `viewerTopBar` · `viewerBottomBar`, 어두운 반투명 `#E6202124`)
  - 위: ← (뒤로 키와 같은 길 — 지휘자면 연주자에게 목록 복귀 알림) · 곡 제목(목록과 같은 서버 제목) · 쪽(`updatePageInfo` 가 채움)
  - 아래(코드에서 채움 `renderBottomBar`): **▶ 연주**(연주 메뉴 · 연주자면 연주자 메뉴) · **👁 보기** · **✏️ 메모**(쓸 수 있는 기기). 오른쪽 96dp 는 🎙 자리
  - 휴대폰 가로: 위 막대 없이 아래 막대 끝에 쪽
  - **가운데 한 번 탭 = 보이기 · 숨기기**(`barsRequested`). 끝 · 처음 안내가 떠 있으면 안내 닫기가 먼저(예전 OK 짧게와 같음)
  - **연주가 시작되면 접힌다**(§9-2) — 악보 연동 PLAYING · 🎤 듣기 · 메트로놈 · 합주 따라가기. `refreshViewerBars()` 를 상태가 바뀌는 곳에서 부른다: 마디 박스 다시 그리기(`refreshScoreOverlay` — 마디 · 쪽 · 상태가 바뀔 때마다), `startMetronome` · `stopMetronome`, `refreshVoiceButton`(🎤 켜고 끌 때), 메모 모드 들고 날 때, `updatePageInfo`
  - 막대가 보이는 동안 가운데 아래 쪽 정보 글(`pageInfo`)은 INVISIBLE(겹침). 설정에서 끈 경우(GONE)는 그대로
  - 메모 모드에서는 막대를 접고 메모 도구 줄(위)만 — P17 §4 의 "도구 줄이 아래 막대 자리에"는 하지 않았다(옮길 까닭이 적음)
- **마디 고르는 중** 아래 막대가 저절로: **▶ N마디부터 시작 · 🎤 N마디부터 듣기**(마이크 · 연주자 아님 · 듣는 중 아님) **· 취소 · ⋯**(연주 메뉴 — 메트로놈 설정 · 반주, 예전 고르는 중 두 번 탭). 떠 있던 `micStartButton` 과 그 배경 drawable · `refreshMicStartButton` 은 지웠다(터치 기기에서만 보이던 단추)
- **두 번 탭 없앰**(§9-1): `GestureDetector.setOnDoubleTapListener(null)` — 한 번 탭이 `onSingleTapUp` 로 바로 온다
  - 고르는 중 마디 탭도 이제 기다림 없이 고르기 · 시작(#087 이 두 번 탭과 헷갈리지 않게 두었던 확인 기다림이 필요 없어짐)
  - 고르는 중 마디 밖 가운데 탭은 예전엔 OK 짧게 = 시작이었다 → 이제 막대 토글(아래 막대는 고르는 중이라 그대로) — 빈 곳을 눌러 시작해 버리는 일이 없다
  - 옆을 빨리 두 번 치면 예전엔 한 쪽(두 번째 탭이 두 번 탭으로 먹힘), 이제 두 쪽
- 막대에서 시작한 터치는 몸짓 · 메모로 보내지 않는다(`dispatchTouchEvent` — 메모 도구 줄 · 🎙 와 같이)
- `sheetMenus()` → `touchShell()`(시트와 막대가 같은 조건)
- 문서: `docs/Viewer_Menus.md` "여는 법" 표 · 막대 설명, `docs/User_Manual.md`, CLAUDE.md 태블릿 줄
