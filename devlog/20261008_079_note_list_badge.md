# 079 — 곡 목록의 메모 · 동기화 필요 표시

2026-10-08 · P11 후속 · 사용자 요청: "곡 목록에서 메모가 있다는 걸 표시해 주면 좋겠고, 동기화가 필요하다는 것도"

## 지금의 메모 동기화 (정리)
- 메모는 쓰는 즉시 곁 파일(`.notes.json` · `.conductor.notes.json`)에 저장되고, 서버로는 **악보 동기화 때 함께** 오간다
  - 앱 시작(조용히) · 목록의 🔄 · 설정 "지금 동기화"
- 메모를 쓴 직후 자동으로 올리지는 않는다. 오프라인이어도 곁 파일에 남고, 다음 동기화에서 합친다(서버 ∪ 내가 더한 것 − 내가 지운 것)
- 받은 상태는 곁 파일의 `sync.base_ids`. 지금 id 집합과 다르면 올릴 것이 있다

## 무엇
- 목록 카드 제목 줄 끝(파트 이름 뒤)에 작게
  - 메모가 있으면 `✏️`(회색)
  - ScoreMate 에서 받은 악보이고 올리지 못한 변경이 있으면 `✏️ 동기화 필요`(주황) — 지운 것만 있어도(메모가 0개여도) 표시
- `ScoreNotesSync.badgeOf(pdf)`: 개인 겹은 늘 쓸 수 있으니 `ids != base_ids`(동기화 전이면 메모가 있으면), 지휘자 겹은 쓸 수 있을 때만(`sync.writable`)
  - 이전의 `hasUnsent` 는 지휘자 겹 보관용 — 개인 겹은 `writable` 을 적지 않아 늘 false 라 따로 만들었다
- 목록은 뷰어에서 돌아올 때(onResume) 다시 읽으므로 메모를 쓰고 나오면 바로 보인다. 동기화가 메모만 올리거나 받았어도(`notesUploaded` · `notesDownloaded`) 목록을 다시 읽는다
- 연결하지 않은 로컬 서재 악보는 ✏️ 만(주고받지 않으므로)
