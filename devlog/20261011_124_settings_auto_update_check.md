# 124 — 설정 화면에서도 10분마다 업데이트 자동 확인

2026-10-11 · 사용자: "설정 화면에서도 10분마다 새 업데이트 체크하게 해줘."

## 왜
자동 확인은 파일 목록(첫 화면)이 앞에 있을 때만 돌았다(#054 · MainActivity 1분 틱). 설정 화면에 머물면(업데이트 확인을 시험하거나 설정을 만지는 동안) 확인이 멈췄다 — 서버 기기 기록에서도 22분 동안 확인이 없는 것으로 보였다(#120).

## 바꾼 것
- `SettingsActivity` 에도 같은 1분 틱 → `UpdateController.checkIfDue()`. 10분 시계(`nextAutoCheckAtMs`)는 프로세스에 하나라 **파일 목록과 설정이 나눠 쓴다** — 화면을 오가도 10분에 한 번
- 같은 조건: 자동 확인 켜짐 · 창에 포커스(대화상자가 없을 때) · 합주 중 아님. onPause 에서 멈추고 onResume 1.5초 뒤 다시
- 새 버전이 있으면 설정 화면 위에 같은 알림. 에뮬레이터는 여전히 안 함(#121)
- 설정 줄 설명 "파일 목록에서 10분마다" → "파일 목록 · 설정 화면에서 10분마다"
