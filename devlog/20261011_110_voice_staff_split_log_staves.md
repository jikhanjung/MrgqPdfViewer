# 110 — "보표 23" = 보표 2 · 3, 음성 기록에 보표 이름

2026-10-11 · [#109](20261011_109_voice_real_recordings_eval.md) 의 남은 것 · 사용자: "계속 진행해줘"

## 바꾼 것
- **붙여 적은 보표 번호 나누기**: STT 가 "보표 2 3"을 "보표 23"(또는 "목표 23")으로 붙여 적는다(아르페지오네, 실녹음). 파서가 이제 **파트 보기 목록의 보표 수**(`staffCount`)를 받아,
  보표 뒤 두 자리 수가 보표 수보다 크고 두 숫자가 모두 있는 보표 번호이며 서로 다르면 둘로 나눈다(`CommandParser.staffNumbers`). 보표 수를 모르거나(null) 그만큼 보표가 있으면(보표 12 / 20개) 그대로
  - `parse` · `parseBest` 에 `staffCount: Int? = null` — 악보 화면은 이미 읽어 둔 파트 목록의 크기(`voiceStaffCount`)를 넘긴다
- **음성 기록(`commands.jsonl`)에 `staff_names` · `staff_count`**: #109 에서 이름 실패를 다시 읽으려면 그때 악보의 보표를 따로 알아내야 했다. 이제 줄마다 남는다(기기 밖으로 보내지 않는 원칙은 그대로 — adb 로 가져와 볼 때만)
