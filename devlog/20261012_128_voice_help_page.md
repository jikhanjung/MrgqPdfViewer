# 128 — 🎙 음성 명령 도움말: "도움말" · "사용법" → 안내 페이지, 조용하면 안내

2026-10-12 · 사용자: "버튼 누르고 아무 말도 안 하고 있으면 "도움말" 이라고 말하면 도움말을 보여준다고 안내 메시지를 보여줘. 그리고 "도움말" 혹은 "사용법" 이라는 입력이 들어오면 음성명령으로 할 수 있는 일들을 안내하는 페이지를 띄워줘. 확인 누르면 닫고. 주로 사용되는 개별 명령들에 대한 설명과 대표적인 사용법 (복합적인 것들까지) 들을 안내페이지에서 간단명료하게 보여주면 되겠지."

## 바꾼 것
- **도움말 페이지**(`showVoiceHelp`, 악보 화면): 제목 "🎙 음성 명령", 한 줄 소개, 묶음 여섯 — 마디 · 시작 / 쪽 / 메트로놈 / 파트 / 🎤 연주 듣고 넘기기 / **한 번에 말하기**(템포 + 마디, 파트 + 레터, 예비박 + 처음부터, 파트 + 쪽) — 줄마다 굵은 연한 파랑 "“말할 문장”" + 뜻. 맨 아래 "알아 둘 것"(누른 채 말하고 떼기 · 짧게 = 정지, 수만 말하면, 헷갈리는 말은 실행 안 함, 사람 이름 보표 — 한국어만). 스크롤, **확인**으로 닫는다
- 내용은 `voice/VoiceHelp`(JVM): 문장은 **음성 언어**로(한 · 영 짝), 뜻 · 묶음 제목은 **앱 언어** 리소스(`voice_help_*`) — 한국어 화면 + 영어로 말하기도 맞게 보인다
- **부르는 말**: "도움말" · "사용법" · "사용 방법" · "헬프" · "help" · "how to use" · "what can I say" — 음성 언어와 관계없이 둘 다. 첫 후보가 도움말이면 바로, 아니면 명령으로 읽힌 후보가 없을 때만(명령을 막지 않게). 👂 계속 듣기("메이트, 도움말")도 같다. 인식 힌트에 "도움말 · 사용법" / "help · how to use"
- **조용하면 안내**: 🎙 를 누른 채 2.5초(`VOICE_HELP_HINT_MS`) 동안 중간 결과가 없으면 "🎙 듣는 중…" 아래에 "“도움말”이라고 말하면 쓸 수 있는 명령을 보여 줘요"(영어 음성이면 “help”). 아무 말 없이 끝나 인식이 "못 알아들었어요"(NO_MATCH · SPEECH_TIMEOUT)로 끝날 때와, 말은 들렸지만 명령이 하나도 없을 때(`NOTHING`, 🎙 만)도 같은 줄을 붙인다
- 기록(`commands.jsonl`)에는 고른 말 = 도움말 문장, 결과 "도움말"
- 단위 테스트 `VoiceHelpTest`: 페이지의 모든 문장이 실제 명령이 되고 **한 · 영 짝이 같은 명령**인지, 페이지 문장이 도움말로 읽히지 않는지, 부르는 말 · 아닌 말("helpful" · "도움이 필요해")
- `docs/Voice_Commands.md` 에 도움말 줄 · 영어 표 한 줄
