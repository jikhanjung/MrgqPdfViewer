## 0. 목표

앙상블 리더가 ScoreMate 서버(웹)에 올린 악보가 **멤버의 TV 에 저절로 들어와 있게** 한다. 수정판을 올리면 TV 는 다음 동기화에서 새 판으로 바뀐다.

바뀌지 않는 것:
- **합주 실시간 동기화는 LAN 그대로** (#055: 마디 전환 차이 2.5 ms). 서버는 배포만 한다
- **오프라인 우선** — 받은 악보는 앱 폴더에 있고, 서버 · 인터넷이 없어도 모든 기능이 돈다
- 웹 업로드(로컬 웹 서버) · 지휘자에게서 받기 등 지금의 넣는 방법도 그대로

## 1. 사용자 흐름

1. 설정 → **ScoreMate** → "연결" → 화면에 코드 `BCDF-GHJK` 와 QR
2. 휴대폰으로 QR → 로그인 → "이 TV 연결" (서버 계획 §3)
3. TV 가 토큰을 받고 바로 동기화 → 파일 목록에 앙상블 악보가 ☁️ 표시와 함께 나타난다
4. 이후 앱을 켤 때(업데이트 확인과 같은 시점) · 파일 목록에서 수동으로 동기화
5. 설정에서 "연결 해제" — 받은 악보를 남길지 지울지 묻는다

## 2. 구조

| 부품 | 내용 |
|---|---|
| `scoremate/ScoreMateClient` | HTTP (업데이트 기능의 `HttpURLConnection` 방식) — device code · token 폴링 · refresh · sync · download |
| `scoremate/DeviceLinkDialog` | 코드 · QR 표시, 폴링(서버 `interval`), 만료 시 새 코드 |
| QR 생성 | `com.google.zxing:core` (순수 Java, 작다) → Bitmap |
| 토큰 저장 | 앱 전용 SharedPreferences (앱 샌드박스). refresh 만료 · 해제되면 "다시 연결" 안내 |
| `scoremate/ScoreSync` | 커서로 변경분 받기 → 새 버전 다운로드(`.part` → **SHA-256 검증** → 교체, `UpdateClient` 재사용) → 지워진 악보 처리 |
| DB (v13) | `server_scores`(serverId, pdfFileId, versionNumber, sha256, ensembleName, partName, syncedAt) + `scoremate_state`(cursor) |
| 저장 위치 | `PDFs/ScoreMate/<앙상블>/<제목>[ (파트)].pdf` — 기존 파일과 섞이지 않게. 파일 목록은 하위 폴더도 보이게 |

## 3. 판단이 필요한 지점

- **새 판으로 바뀌면** 파일 내용이 바뀐다 → `PdfFileSync` 가 파일 변경을 감지해 페이지 수 · 문서 정보 · **악보 분석(마디)을 다시** 한다. 파일별 표시 설정(두 페이지 · 클리핑 · 메트로놈)은 **유지**(같은 pdf_files 레코드를 update — REPLACE 금지 규칙)
- **보는 중에 새 판이 오면** 바로 바꾸지 않고, 그 파일을 닫은 뒤 교체
- **TV 에서 동기화 악보를 지우면**: 목록에서 숨김(다음 동기화에서 다시 받지 않음). 설정에서 "숨긴 악보 다시 받기"
- **합주 모드와의 관계**: 지휘자가 `file_change` 로 파일 이름을 보내면, 연주자 TV 에 같은 앙상블 악보가 이미 동기화돼 있어 LAN 다운로드가 필요 없다 — 파일 이름 규칙을 앙상블 안에서 같게 유지하는 것이 중요 (위 저장 위치 규칙)
- 인터넷이 없을 때: 조용히 건너뛴다 (업데이트 확인과 같은 정책). 합주 모드 중에는 동기화하지 않는다(다운로드가 LAN 대역을 쓰지 않게)

## 4. 단계 (서버 단계와 맞춤)

| 단계 | 클라이언트 | 선행 서버 |
|---|---|---|
| C1 | ScoreMate 설정 화면 · 서버 URL · 연결 흐름(코드 + QR + 폴링) · 토큰 저장 · 해제 | S3 |
| C2 | 동기화: 목록 · 다운로드 · SHA-256 · 새 판 교체 · 지운 악보 · DB v13 | S4 |
| C3 | 파일 목록 ☁️ 표시 · 앙상블 · 파트 · 판 번호, 시작 시 자동 동기화 | S4 |
| C4 | (2차) 세트리스트 = 연주회 곡목 화면, 서버 악보 분석 결과 받기 | S6 |

테스트: 순수 로직(커서 · 판 비교 · 파일 이름 규칙 · 폴링 상태)은 JVM 단위, 다운로드 교체 · DB 는 계측, 실기기는 Z18TV Pro · Google TV Streamer.
