## 0. 한 줄

**TV 화면은 그대로 두고**, 태블릿 · 휴대폰(`DeviceForm` 이 TV 가 아님)에서만 껍질을 터치용으로 바꾼다 — 악보 화면에 **탭하면 나오는 도구 막대**,
메뉴는 가운데 목록 대화상자 대신 **스위치가 든 하단 시트**, 메트로놈 설정 · 곡 목록 · 설정을 터치 배치로. 넘김 · 악보 연동 · 메모 · 음성의 동작은 바꾸지 않는다.

## 1. 왜

- 지금 터치는 **리모컨 키를 흉내 낸다**(#066 1단계: 가운데 탭 = OK, 두 번 탭 = ↑, 길게 = OK 길게). 동작은 다 되지만 화면에 아무 표시가 없어 **메뉴가 있는지 모른다**
- 메뉴 · 대화상자는 포커스로 움직이는 TV 목록이다. 켜고 끄는 줄도 누르면 닫혔다 다시 열리고, 슬라이더는 ←→ 때문에 "상세…"를 제목 줄로 옮겨 두었다(#057)
- 곡 목록의 세트리스트 줄은 **포커스로 바뀌고**, 설정은 TV 두 칸 카테고리다
- 기능이 태블릿 · 휴대폰 쪽(🎤 · 🎙 · ✏️ 메모)으로 많이 늘었는데 껍질은 아직 TV 다

## 2. 지금 모습 — 터치에서 어색한 곳

| 화면 | 지금 | 터치에서의 문제 |
|---|---|---|
| 악보 화면 | 좌 · 우 1/3 탭 = 넘김, 밀기 = 넘김, **가운데 탭 = 쪽 정보**, **가운데 두 번 탭 = 연주 메뉴**, **길게 = 보기 메뉴**(`touchGestures`) | 메뉴가 보이지 않음. 가운데 한 번 탭은 두 번 탭인지 기다리느라 늦게 반응 |
| 떠 있는 단추 | 🎙(오른쪽 아래) · "🎤 N마디부터 듣기"(마디 고르는 중) · ✏️ 메모 도구 줄 | 저마다 따로 떠 있어 자리 규칙이 없다 |
| 연주 · 보기 · 연주자 메뉴 | `AlertDialog` 목록(`showMetronomeMenu` · `showPdfDisplayOptions` · `showPerformerEnsembleMenu`) | 켜기 · 끄기도 누르면 닫힘, 줄이 작고 화면 가운데 |
| 메트로놈 설정 | 박자 · 속도 · 크기 세 줄 + 줄마다 "상세…"(`showMetronomeDialog`) | 터치는 ←→ 제약이 없어 한 화면에 펼쳐도 된다 |
| 곡 목록 | 세트리스트 줄이 포커스로 바뀜, 🔄 동기화 단추, 휴대폰은 머리줄만 줄임(`compactForPhone`) | 포커스가 없다 — 탭 · 칩 · 당겨서 동기화가 익숙하다 |
| 설정 | 이모지 카테고리 목록 + 상세 칸(`detailPanelLayout`), 값은 부제목 "켜짐/꺼짐" | 휴대폰은 한 칸씩 들어가는 목록, 켜기 · 끄기는 스위치가 맞다 |

## 3. 원칙

1. **TV 는 바뀌지 않는다** — 리모컨 키 · 포커스 · 대화상자 그대로. TV 쪽 확인은 "달라진 게 없다"만
2. **기기 종류로 껍질을 고른다** — `DeviceForm.isTv` 면 지금 것, 아니면 터치 것. 태블릿(세로)과 휴대폰(가로 · 세로)은 같은 터치 껍질, 크기만 다르게
3. **메뉴 내용과 그리는 방식을 나눈다**
   - 내용(`ViewerMenus` — 줄 · 상태 · 보일 조건 · 눌렀을 때)은 한 곳. P13 의 "한 항목은 한 메뉴에만" · "못 쓰는 줄은 숨김"이 기기와 상관없이 지켜진다
   - 그리기: TV = 지금 `AlertDialog`, 터치 = 하단 시트 · 도구 막대
   - 내용은 Android 에 의존하지 않게 — 단위 테스트로 보일 조건을 고정하고, P14 에서 iOS 가 그대로 쓴다
4. **도구는 지금 것** — Android View + Material Components(이미 `material:1.11.0`). Jetpack Compose 로 다시 짜는 것은 이 계획 밖
5. **메뉴를 여는 것 = 일시정지**는 그대로 — 하단 시트도 창이라 `onWindowFocusChanged` 판단(#053)이 같다
6. 터치 크기 48dp 이상, 시스템 막대 · 제스처 영역(insets) 피하기

## 4. 악보 화면 — 도구 막대

```
┌──────────────────────────────────────────┐
│ ←  곡 제목 (파트)               3 / 12 쪽 │  ← 위 막대 (얇게)
│                                          │
│              (악보 — 그대로)               │
│                                          │
│  ▶ 연주     👁 보기     ✏️ 메모        🎙  │  ← 아래 막대
└──────────────────────────────────────────┘
```

- **가운데 한 번 탭 = 막대 보이기 / 숨기기.** 쪽 정보(지금 가운데 탭)는 위 막대가 대신한다
- 터치 기기에서 **가운데 두 번 탭은 없앤다** → 한 번 탭이 기다림 없이 바로 반응. 연주 메뉴는 ▶ 로
- **길게 누르기는 남긴다**(보기 메뉴 지름길 · 🎤 듣는 중 마디 다시 맞춤, #087)
- 좌 · 우 탭 넘김 · 밀기 · 페달 · 휴대폰 세로 끌기는 그대로. 막대가 떠 있어도 옆 탭은 넘김
- **연주가 시작되면 막대는 숨는다**(악보 연동 · 🎤 · 합주 따라가기). 멈추면 다시 보이지 않고 탭을 기다린다
- **마디 고르는 중**에는 아래 막대가 그 상황 막대로 바뀐다: `▶ 57마디부터 시작 · 🎤 57마디부터 듣기 · 취소 · ⋯` — 지금 떠 있는 "🎤 N마디부터 듣기" 단추(`micStartButton`)와 두 번 탭 메뉴를 대신한다(⋯ = 연주 메뉴 — 메트로놈 설정 · 반주, 2단계에서 더함)
- **합주 연주자**: ▶ 자리에 "따라가는 중 · 빠지기 / 합류"(연주자 메뉴)
- ✏️ 를 누르면 막대는 접히고 메모 도구 줄(`noteToolbar`, 화면 위)만 — 메모를 끝내면 막대가 돌아온다 (2단계 구현: 도구 줄 자리를 옮기지 않음)
- 🎙 는 막대가 숨어도 **늘 떠 있다**(누른 채로 말하기 — 연주 중 쓰는 단추). 막대가 보이면 막대 오른쪽 끝에 붙는다
- 휴대폰 가로는 높이가 빠듯하다 → 위 막대 없이 아래 막대에 쪽 번호까지

## 5. 메뉴 → 하단 시트

| 줄 종류 | TV (지금) | 터치 |
|---|---|---|
| 동작 (시작 · 정지 · 마디 골라 다시) | 목록 줄 | 큰 단추 줄 — 누르면 시트 닫힘 |
| 켜기 · 끄기 (마디 박스 · 메모 보이기 · 반주) | "마디 박스: 켜짐" 줄, 누르면 닫힘 | **스위치** — 시트는 열린 채 바로 바뀜 |
| 고르기 (두 쪽 · 파트) | 줄 → 다음 대화상자 | 줄 → 다음 시트(또는 칩) |
| 값 (자르기 · 여백 · 반주 크기) | 줄 → 슬라이더 대화상자 | 시트 안 슬라이더 |

- 연주 · 보기 · 연주자 메뉴 셋 다. 내용 · 순서는 `docs/Viewer_Menus.md` 그대로
- 태블릿은 시트 폭을 600dp 정도로 줄여 가운데, 휴대폰 가로는 높이를 넘으면 시트 안에서 스크롤
- 파트 보기 대화상자(`showPartViewDialog`)는 체크 목록이라 시트로 옮기기만

## 6. 메트로놈 설정

- 터치에서는 "상세…" 없이 **한 화면**: 박자(칩) · 점음표 박 · 속도(슬라이더 + −/+ · 숫자 누르면 입력) · 소리 크기 · 클릭음 · 예비박 · 구간별 빠르기(구간 목록)
- 태블릿은 한 화면, 휴대폰은 스크롤
- 탭 템포("탭해서 빠르기 맞추기")는 터치에서 자연스럽지만 새 기능이라 이 계획 밖 — 열린 질문

## 7. 곡 목록 · 설정

- **곡 목록**
  - 세트리스트 줄 → 가로로 미는 **칩(또는 탭) 줄**, 탭으로 고름
  - **당겨서 동기화**(`SwipeRefreshLayout` — 의존성 추가), 🔄 단추는 남겨도 됨
  - 머리줄 단추(합주 · 설정)는 아이콘 단추로, 휴대폰 `compactForPhone` 은 이 배치에 흡수
- **설정**
  - 터치는 **한 칸**: 카테고리 목록 → 누르면 상세가 화면 전체(← 뒤로), 켜기 · 끄기는 스위치
  - TV 의 두 칸 · 포커스 이동은 그대로

## 8. 단계

| 단계 | 내용 | 끝난 기준 |
|---|---|---|
| **0** | 테마를 Material 다리 테마로(`Theme.MaterialComponents…Bridge` — 지금 `Theme.AppCompat` 위에서 시트 · 스위치 · 칩이 제대로 그려지게), 메뉴 내용 모델 `ViewerMenus` 를 떼고 **TV 그리기만**으로 연결 | 화면 변화 없음(TV · 터치 모두), 보일 조건 단위 테스트, beta |
| **1** | 터치에서 연주 · 보기 · 연주자 메뉴를 **하단 시트**로 | 태블릿 · 휴대폰에서 스위치로 바로 바뀜, 일시정지 · 정지 규칙 그대로 |
| **2** | **도구 막대**(태블릿 먼저 → 휴대폰), 가운데 두 번 탭 없앰, 마디 고르기 상황 막대 | 처음 쓰는 사람이 설명 없이 메뉴를 찾는다, 연주 중 막대가 숨는다 |
| **3** | 메트로놈 설정 터치 배치 | 한 화면에서 박자 · 속도 · 예비박 |
| **4** | 곡 목록 — 칩 · 당겨서 동기화 | 세트리스트를 탭으로 고름 |
| **5** | 설정 — 한 칸 · 스위치 | 휴대폰에서 모든 설정에 닿음 |

- 단계마다 beta 하나. TV(Z18TV Pro)는 "달라진 게 없다"만 확인
- 계측 테스트 에뮬레이터(API 30 · 34)는 **휴대폰 꼴**이라 터치 껍질로 돈다 — 대화상자를 찾는 계측 테스트가 있으면 같이 고친다
- 끝나면 `docs/Viewer_Menus.md` 의 "여는 법" 표 · `docs/User_Manual.md` 를 고친다
