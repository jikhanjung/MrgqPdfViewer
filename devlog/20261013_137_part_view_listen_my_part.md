# 137 — 파트 보기에서 듣고 넘기기: 내 파트만 듣기 · 조용함 = 쉼 (v0.8.4-beta.2, P21 2단계)

2026-10-13 · 계획 [`P21`](20261013_P21_accompaniment_parts_part_listen_plan.md) · 사용자: "파트를 연습할 때 듣고 넘기기를 하면 내 파트만 듣고 악보 상의 위치를 파악하게 하면 좋겠고"

## 전
🎤 듣고 넘기기(P10)는 전체 악보에서만 — 파트 보기면 "전체 악보에서만 쓸 수 있습니다". 기준 크로마는 모든 파트의 음.
혼자 파트를 연습하면 다른 파트의 음은 들리지 않는데 기준에는 들어 있었다.

## 한 것
- 파트 보기 막기를 뺐다. **기준 크로마 = 내 파트만** — 보고 있는 보표에 걸친 MusicXML 파트(`ScoreChroma.build(parts=)`, 반주의 "내 파트"와 같은 기준).
  못 찾으면 "보고 있는 파트를 MusicXML 에서 찾지 못했습니다"
- 마디 자리 · 쪽 · 반 쪽 넘김은 **파트 PDF 좌표**(`PartLayout.mapMeasures` — 마디 박스 · 메트로놈 연동과 같은 것). MusicXML 맞춤 검사는 원본 마디로
- **쉼 문제**: 내 파트만의 기준엔 빈 칸(쉼)이 많다. 전처럼 d = 1 − 코사인이면 빈 칸은 무엇과도 1 이라, 쉬는 동안 정렬이 쉼 앞 음에 붙어 있다가
  다시 들어올 때 늦는다. 그래서 **조용함을 쉼과 맞춘다**(`quietGate`, 파트 보기에서만):
  - `MicScoreFollower`: 소리 크기가 바닥(지금까지 1초 평균의 최소 — 대개 연주 전 고요)의 2배(+6dB) 아래이고 −54 dBFS 아래면 **조용한 칸** → 정렬기에 빈 칸으로
    - 기준: 태블릿 기록(아르페지오네 10-09 15:13, UNPROCESSED) — 연주 전 약 −58 ~ −60 dBFS, 연주 −31 ~ −39, 여린 대목 1초 평균 −45 ~ −50.
      −54 상한은 바닥을 못 잡아도(곧바로 연주) 여린 소리를 조용함으로 보지 않게. 시끄러운 방이면 조용한 칸이 없어 전과 같다
  - `OnlineAligner.cost`: 녹음 칸이 비었으면 악보도 빈 칸일 때 0, 아니면 1. 비지 않은 녹음 칸은 전과 같다 — **전체 악보 듣기는 바뀌지 않는다**
  - 쉬는 동안 정렬기의 날것 추정은 쉼 끝(다시 들어올 자리)으로 가서 기다리고, 관성 거르개(`InertialTracker`)는 기울기 0 을 옮김으로 받지 않아
    **고른 빠르기로 쉼을 세며** 간다 — 쉼 사이에 쪽이 바뀌면 제때 넘긴다. 다시 들어오면 거기서 맞는다
  - 시작 찾기(`StartDetector`)에는 늘 그대로 넣는다 — 조용함이 쉼과 맞아 연주 전 고요를 시작으로 보지 않게
- 기록 JSON: `info.parts`(들은 파트 · 전체면 all), `quiet_gate`, `pos` 사건의 `quiet`(지난 기록 뒤 조용한 칸 수) — 실제 혼자 연습 녹음으로 문턱을 다듬을 자료

## 계획과 다른 점
P21 은 "먼저 Python 실험"이었지만 **혼자 파트만 친 녹음이 없다**(태블릿 기록은 모두 피아노 + 아르페지오네 함께). 그래서 전체 악보 경로는 그대로 두고
파트 보기에서만 켜지는 방식으로 넣고, 합성 시험(아래)으로 쉼 처리만 확인했다. 실제 혼자 연습 기록이 생기면 `data/` 스크립트로 문턱 · 성적을 잰다.
