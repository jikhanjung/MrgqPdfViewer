# 053 — 메트로놈 메뉴(↑)와 악보 연동 일시정지

작성일: 2026-09-13
선행: [`050`](20260913_050_time_signature_and_score_follow.md)(악보 연동), [`052`](20260913_052_metronome_dotted_beat.md)(점음표 박)

## 0. 요약

사용자 요청 두 가지:

1. "악보 연동 중에 메뉴를 띄우면 메트로놈을 일시정지 해줘" — 메뉴를 닫을 때는 **"그 자리에서 재개, 마디 새로 선택해서 다시 시작, 그냥 멈춘 채로 끝"** 중에서 고르게.
2. "메트로놈 메뉴만 따로 떼어내서 위쪽 화살표를 눌렀을 때 보여주는 것도 괜찮을 것 같아. 이건 좀 더 자주 사용할 수도 있을 것 같거든.
   하다가 멈추고 다시 특정 마디부터 시작할 수도 있어야 하고."

두 요청을 하나로 묶었다 — **↑ 메트로놈 메뉴가 곧 일시정지 후 고르는 메뉴다.**

| 상황 | ↑ 메뉴 항목 |
|---|---|
| 악보 연동 중 | (먼저 일시정지) **이어서 — N번 마디부터 (예비박 한 마디 뒤)** · **마디 골라 다시 시작** · **정지** · 메트로놈 설정… |
| 일반 메트로놈 실행 중 | 정지 · 메트로놈 설정… |
| 꺼져 있음 | 시작 — 악보에서 마디 고르기 · 메트로놈 설정… |

- OK 길게(PDF 표시 옵션)도 악보 연동 중이면 일시정지한다. 옵션 메뉴와 거기서 연 대화상자를 **모두 닫으면** 같은 선택 메뉴가 뜬다
- 선택 메뉴에서 "메트로놈 설정…" 을 골라 템포·박자를 바꾸고 닫으면 선택 메뉴가 다시 뜬다 — 바꾼 설정으로 이어서 시작할 수 있다
- 선택 메뉴를 **고르지 않고 닫으면(뒤로) 정지** ("멈춘 채로 끝"). 일시정지로 남겨 두면 할 일이 없는 상태가 된다
- 시작 마디 선택은 **마지막으로 멈춘 마디가 화면에 있으면 거기서** 커서를 시작한다 (정지 후 다시 시작할 때도)

### "그 자리에서 재개" 의 해석

멈춘 박 그대로 이어 울리면 연주자는 박을 다시 잡을 틈이 없다. **멈춘 마디의 처음부터, 시작할 때처럼 한 마디 예비박 뒤** 이어 간다.
멈춘 마디는 커서 모양(파란 상자)으로 표시해 두어 어디서 이어지는지 보인다.

## 1. 구현 (PdfViewerActivity)

- `FollowState` 에 `PAUSED`. `pauseFollowing()` — 엔진 정지, 박 표시 숨김, `followMeasure`·`cursorIndex` 를 멈춘 마디로.
  `resumeFollowing()` = `startFollowing()` (cursorIndex 마디부터 예비박). `reselectFromPause()` → `enterMeasureSelection`
- `showMetronomeMenu()` — 상태별 항목 목록 (위 표). 고르지 않고 닫히면 PAUSED 에서 정지
- `startMetronomeWithSavedSettings()` — ↑ 메뉴의 "시작" 은 설정 대화상자를 거치지 않으므로 이 파일의 저장값(없으면 악보 박자표)을 엔진에 넣는다.
  설정 읽기는 대화상자와 같은 `metronomeSettingsFor()` 로 뽑았다
- **메뉴를 모두 닫은 순간** 은 `onWindowFocusChanged(hasFocus = true)` 로 안다 — 대화상자가 떠 있는 동안은 액티비티 창이 포커스를 잃는다.
  옵션 메뉴 → 설정 대화상자처럼 넘어가는 사이(특히 설정 대화상자는 설정을 읽고 악보를 분석한 뒤 뜬다) 포커스가 잠깐 돌아올 수 있어
  **300ms 뒤 다시 확인**하고, 설정 대화상자 준비 중(`metronomeDialogPending`)이면 띄우지 않는다
- 키: 선택 중 ↑ 는 지금처럼 이전 줄로 커서 이동. 그 밖의 뷰어 상태에서 ↑ 는 메트로놈 메뉴(이전엔 쓰지 않던 키). 연주·일시정지 중 뒤로는 정지
- 다른 파일로 넘어가면 일시정지도 정지. 액티비티 `onPause` 는 기존대로 정지

## 2. 검증

에뮬레이터(`Television_1080p_2`, API 30 Google TV)에서 임시 계측(커밋 안 함)으로 **리모컨 키 이벤트만** 보내 확인 (240 BPM, 6/8):

| 동작 | 결과 |
|---|---|
| 꺼진 상태 ↑ → OK("시작") | 마디 선택 (`SELECTING`) |
| 연주 중(마디 3) ↑ | `PAUSED`, 마디 3, 엔진 정지, 메뉴 표시 |
| OK("이어서") | `PLAYING` 마디 3 예비박(박 0) → 2초 뒤 예비박 끝 마디 3 → 4초 뒤 마디 4 |
| ↑ → ↓ OK("마디 골라 다시 시작") | `SELECTING`, 커서 = 멈춘 마디 4 → → 5 → OK → 마디 5 예비박부터 |
| ↑ → ↓↓ OK("정지") | `OFF`, 뷰어는 그대로, 마지막 위치 = 마디 5 |
| OK 길게 | `PAUSED` + "PDF 표시 옵션"(메트로놈 항목에 "(일시정지)") → 뒤로 닫으면 선택 메뉴가 뜸 |
| 선택 메뉴 → "메트로놈 설정…" → 닫기 | 선택 메뉴가 다시 뜸 |
| 선택 메뉴에서 뒤로 | `OFF` (정지), 뷰어는 그대로 |
| 정지 후 ↑ → "시작" | 커서 = 마지막으로 멈춘 마디 |

화면: 일시정지 메뉴가 악보 위에 뜨고 멈춘 마디(2)에 파란 커서 상자 — 스크린샷으로 확인.
