# 093 — 🎙 음성 명령에서 "(시험)" 떼기 · 👂 계속 듣기 잠시 끄기

2026-10-10 · #085 · #091 · #092 후속 · 사용자: "음성 명령 설정 버튼에서 (시험) 빼줘." → "계속 듣기 버튼은 일단 disable."

## 🎙 음성 명령
누른 채 말하기는 태블릿 · 휴대폰에서 잘 동작한다(#084 이후). 설정 → 앱 정보의 제목을 "음성 명령 (시험)" → **"음성 명령"** 으로 바꿨다.
`docs/Voice_Commands.md` 도 같이 바꿨다. ⌨️ 글자로 명령 시험(P12 1단계 창)은 그대로 둔다.

## 👂 계속 듣기 — 잠시 끔
#092 에서 사용자는 "효용성이 떨어진다, 실제로는 꺼 둘 것 같다"고 했다. 지우지 않고 **스위치 하나로 막는다**:

- `PdfViewerActivity.VOICE_ALWAYS_AVAILABLE = false`
- 악보 화면은 `voiceAlwaysOn()`(= 이 값 && 설정)으로만 본다
  - 전에 👂 를 켜 둔 기기도 듣지 않는다
  - 단추는 🎙 로 돌아온다
  - 알림 소리 음소거(#092)도 걸리지 않는다. 걸려 있던 것은 `refreshVoiceButton` 의 `muteRecognizerBeep(false)` 가 되돌린다
- 설정 → 앱 정보
  - 👂 줄은 흐리게, 누를 수 없게, "지금은 쓸 수 없습니다 — 다듬는 중"으로 보인다
  - 🗣 호출어 줄은 숨긴다
- 저장된 설정(`voice_always_listen` · `voice_wake_words`)은 지우지 않는다. 다시 켜면(값을 `true` 로) 예전 설정 그대로 돌아온다
- 호출어 처리(`WakeWord`) · 단위 테스트는 그대로 둔다
