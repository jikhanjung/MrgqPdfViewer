# 075 — 한 번에 그린 획 여럿 = 메모 하나 (P11, v0.6.0-beta.3)

작성일: 2026-10-07
관련: [`P11`](20261007_P11_score_annotations_plan.md), [`072`](20261007_072_score_notes_ink.md) · [`074`](20261007_074_score_notes_text_move.md)
상태: 🟡 구현 · 단위 테스트 · lint 통과 — 실기기 확인 전

## 1. 왜
사용자(beta.2 를 써 보고, 2026-10-07): "한 번에 그린 (여러 개의 선들로 된) 메모는 전체를 하나로 보는 게 좋을 것 같아. 선을 여러 개 그리고 **확인**을 누르면 그 전체를 하나의 오브젝트로."
글자 · 기호 · 동그라미 + 화살표처럼 획 여러 개가 한 뜻이라 옮기고 지울 때 한 덩이여야 한다.

## 2. 한 일
- 모델: `ScoreNote.Ink.points`(한 획) → **`strokes`**(획 목록). 색 · 굵기는 묶음에 하나. 맞히기 · 옮기기 · 테두리 · 그리기가 모든 획을 본다
- 곁 파일: `"strokes": [[x, y, …], …]`. beta.1 · beta.2 가 쓴 `"points"` 는 한 획 묶음으로 읽는다(사용자 태블릿에 이미 있는 메모). 쓸 때는 늘 strokes → beta.1 · beta.2 앱은 새 파일을 읽지 못한다(그때는 깨진 파일로 보고 덮어쓰지 않으므로 메모가 지워지지는 않는다)
- 뷰어: **그리는 중 묶음**(`notePending`, 저장 전) — 다 그은 획은 여기에 쌓이고 화면에 보인다. 도구 줄 끝 단추가 **확인**(초록, 묶음 → 메모 하나 · 새 id · 묶음 전체로 붙는 보표) / **끝**(메모 모드 닫기)
- 자동 확정: 다른 쪽에 긋기 · 쪽 넘김 · 다른 도구 · 색 · 굵기 바꾸기 · 메모 모드 끝 · 파일 바뀜 · onPause. 지우개 · 옮기기를 시작하면 먼저 확정
- 묶음 안 ↶ · ↷ = 획 하나씩, 묶음이 비면 저장된 메모의 되돌리기
- 메모 모드 밖에서 펜으로 그으면 메모 모드를 연다(도구 줄 → 확인)
- 붙는 보표 표시: 긋는 동안 묶음 + 지금 획 전체로, 묶음이 있는 동안 남겨 둠
- 테스트 +3 (묶음 맞히기 · 지우기, 옮기기 · 왕복, 옛 points 읽기)

## 3. 서버
웹 겹쳐 보기가 `strokes` 를 읽어야 한다 — 서버 세션에 알림(옛 `points` 도 한 획으로).
