# 105 — 설정의 켜기 · 끄기를 스위치로 (P17 5단계)

2026-10-11 · [P17](20261011_P17_touch_ui_shell_plan.md) 5단계 · 사용자: "계속 진행해줘"

## 알게 된 것
- 설정 화면은 **이미 한 칸**이다 — 카테고리 목록을 누르면 상세 칸이 목록 자리를 대신하고(`showDetailPanel`), ← 로 돌아온다. P17 §7 의 "터치는 한 칸"은 할 일이 없었다

## 바꾼 것
- `SettingsItem.checked: Boolean?` — 켜기 · 끄기 줄의 지금 값. 9줄에 넣었다: 합주 메트로놈 소리(연주자) · 동기 페이지 넘김 · 페이지 전환 애니메이션 · 페이지 넘기기 사운드 · 쪽 정보 표시 · 자동 업데이트 확인 · 사전 릴리스 받기 · 🎙 음성 명령 · 👂 계속 듣기(쓸 수 없는 동안은 꺼짐으로)
  - 웹서버 시작/중지는 TOGGLE 이지만 동작 단추라 넣지 않았다
- `item_settings.xml` 끝에 `SwitchMaterial`(누르지 않음 — 줄 전체가 눌린다), `SettingsAdapter` 가 **TV 가 아니면** `checked` 를 스위치로 보인다. 부제목 설명("켜짐 — …")은 그대로 둔다(무엇이 켜지는지 설명이 들어 있다)
- 줄을 누르면 지금처럼 값을 바꾸고 그 칸을 다시 그리므로(`show…Panel`) 스위치도 따라 바뀐다
