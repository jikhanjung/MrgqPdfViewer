# 🎵 MrgqPdfViewer

**v0.4.4** — Android TV · 태블릿 · 휴대폰용 PDF 악보 리더. 리모컨 · 터치 · 페달로 악보를 보고, 메트로놈 · 파트보 · 반주로 연습하고, 여러 기기로 합주한다. 태블릿은 연주를 듣고 스스로 쪽을 넘긴다.

ScoreMate 서버와 연결하면 웹에서 고른 세트리스트의 악보를 받아 곡 순서대로 보고, 서버가 옮겨 둔 MusicXML 로 다른 파트의 반주를 들을 수 있다.

## ✨ 주요 기능

### 📄 악보 보기
- **선명한 렌더링** — 기기 해상도 그대로(1×) 벡터 PDF 를 그려 얇은 오선도 또렷하다
- **두 쪽 모드** — 가로 화면에 세로 악보를 두 쪽씩, 파일마다 기억
- **위/아래 자르기 · 가운데 여백** — OK 길게 → PDF 표시 옵션
- **즉시 넘김** — 앞뒤 쪽을 미리 그려 두고, 350ms 넘김 애니메이션 · 효과음
- **파일 사이 이동** — 마지막 · 첫 쪽에서 좌우 카드로 다음/이전 곡

### 🎼 파트보 보기 (v0.3.0~)
- 총보에서 **내 파트(여러 개도)만** 잘라 세로 악보처럼 이어 붙여 본다 — 선명도는 원본 그대로
- 줄마다 **원본 마디 번호 · 쪽 번호**, 보표 사이에 걸친 덧줄 많은 음 · 빔은 어느 파트 것인지 보고 넓혀 자른다
- 파트 화면에서도 마디 박스 · 메트로놈 악보 연동 · 합주가 그대로 된다
- 만든 파트보는 기기 안에만 둔다

### 🥁 메트로놈 · 악보 연동
- 샘플 단위로 박을 놓아 흔들리지 않는 메트로놈 — 박자 · 빠르기 · 점음표 박 · 구간별 빠르기(박자가 바뀌는 곡)
- **악보 연동** — 악보에서 시작 마디를 고르면 예비박(두 마디) 뒤 현재 마디를 따라가며 쪽을 스스로 넘긴다. ↑ 로 일시정지 · 이어서 · 마디 골라 다시
- 악보 분석 — 벡터 악보(Sibelius · MuseScore 에서 만든 PDF)의 시스템 · 마디 · 박자표(C · ¢ 포함) · 보표를 찾는다

### 🎹 반주 연습 (v0.3.1~)
- 악보 연동 메트로놈을 켜면 **다른 파트의 소리**가 함께 난다 — 파트보로 내 파트를 골랐으면 그 파트는 빼고
- 메트로놈과 같은 박에 맞춰 나므로 빠르기를 늦추면 반주도 느려진다. 반주 크기는 클릭과 따로
- ScoreMate 가 그 악보를 MusicXML 로 옮겨 두었을 때 쓸 수 있다

### 📱 세로 태블릿 (v0.3.4~)
- 같은 앱을 안드로이드 태블릿에 설치 — 세로로 한 쪽씩 본다
- **터치**: 좌우를 누르거나 밀어 넘김, 가운데 두 번 = 메트로놈 메뉴, 길게 = PDF 표시 옵션, 마디를 눌러 시작 마디
- **넘김 페달 · 키보드**: PageUp/PageDown · 미디어 이전/다음 · Home/End
- 목록에서 곡을 한 번 눌러 연다
- 휴대폰에서도 첫 화면 · 목록이 좁은 폭에 맞춰 놓인다 (v0.4.2)

### 📱 휴대폰 (v0.4.3~)
- 악보 화면은 **가로** — 마디 분석이 있는 악보는 **시스템 하나 · 둘씩**(화면 높이에 맞춰), 없으면 한 쪽을 위 · 아래 절반씩
- → ← · 탭 · 밀기로 다음 · 앞 화면, 쪽이 끝나면 다음 쪽
- 메트로놈 악보 연동 · 🎤 연주 듣고 넘기기 중에는 지금 마디가 든 화면으로 저절로 옮겨 간다

### 🎤 연주 듣고 넘기기 (태블릿, v0.4.0~)
- 태블릿 ↑ 메뉴 **🎤 연주 듣고 넘기기** — 마이크로 듣고 지금 치는 마디 · 시스템을 표시하며 쪽을 넘긴다
- **반 쪽 넘김**: 아래 절반을 칠 때 위 절반을 다음 쪽으로 미리 바꿔 넘김 순간에도 악보가 가리지 않는다
- 짧게 헤매도 고른 빠르기로 이어 가고(관성), 연주 시작은 악보 첫머리와 맞는 소리로 찾는다. 손으로 넘기면 거기서 다시
- 합주: 태블릿이 지휘하면 연주자 TV 도 함께 넘어가고(두 쪽 화면은 다 친 쪽 자리만) 지금 시스템을 표시한다
- 쓰려면 곡에 MusicXML · 마디 분석이 있어야 하고(ScoreMate 동기화 곡), 메트로놈 템포를 실제 빠르기 근처로 둔다
- 설정 → 🎤 **녹음 기록**: 추적 때 남긴 녹음을 보고 · 듣고 · 공유하고 · 지운다 (v0.4.1)

### 🎻 합주 (여러 기기)
- **지휘자 · 연주자** — 지휘자가 곡 · 쪽을 바꾸면 연주자도 따라간다. 자동 발견, 없는 악보는 받기
- **합주 메트로놈** — 기기 간 시계 차이를 재서 같은 박에 맞춘다(마디 전환 차이 중앙값 2.5ms). 연주자는 자기 악보의 마디로 스스로 넘긴다
- 지휘자와 연주자가 서로 다른 화면(전체 악보 · 파트보)이어도 맞는다
- 연결할 때 앱 버전이 다르면 알려 준다
- 지휘자는 늘 전체 악보, 지휘자가 합주를 끝내면 연주자도 끝난다

### ☁️ ScoreMate 연결
- 설정 → ScoreMate → QR 코드로 TV 연결
- 웹에서 이 TV 로 보낸 **세트리스트**의 악보를 받아 곡 순서대로 보고 넘긴다 — 곡 메모 📝, 이전/다음 곡도 세트리스트 순서
- 목록에는 곡 제목 · 파트 · 작곡 · 편곡이 보인다
- 서버가 옮긴 MusicXML · 악보 분석도 함께 받아 기기에서 다시 분석하지 않는다

### 🌐 웹 업로드 (ScoreMate 에 연결하지 않은 TV)
- 브라우저로 `http://<TV IP>:8080` 에 접속해 PDF 를 올리고 지운다 (진행률 표시)

### 🔄 앱 안 업데이트
- 파일 목록에서 새 버전을 10분마다 확인해 알린다 — 설정 → 앱 정보 → 업데이트 확인으로도. GitHub 릴리스 APK 를 받아 SHA-256 을 확인하고 설치 화면을 연다

## 🚀 사용 방법

| 리모컨 | 파일 목록 | 악보 화면 |
|---|---|---|
| ↑ ↓ | 파일 · 세트리스트 이동 | ↑ = 메트로놈 메뉴 (시작 · 일시정지 · 파트 보기 · 반주) |
| ← → | — | 이전/다음 쪽 (악보 연동 중 마디 고르기) |
| OK | 열기 | 짧게: 선택 · 길게(0.8초): PDF 표시 옵션 |
| 뒤로 | — | 목록으로 (악보 연동 중이면 메트로놈 정지) |

- **PDF 표시 옵션**: 두 쪽 모드 · 자르기 · 마디 박스 표시 · 메트로놈 · 파트 보기 · 반주
- **합주**: 설정 → 협업 모드에서 한 기기는 지휘자, 나머지는 연주자(자동 발견)
- **태블릿**: 터치 · 페달로 같은 동작 — 위 "세로 태블릿" 참고

## 🛠️ 기술 스택

- Android 11 이상 (minSdk 30) — 실사용 기기 Z18TV Pro · Google TV Streamer (Android 14), 샤오신패드 12.7 (Android 13)
- Kotlin · Coroutines · Room(SQLite, v18)
- PdfRenderer(렌더링) · PdfBox-Android(문서 정보 · 악보 분석 · 파트보 PDF)
- AudioTrack(메트로놈 · 반주 합성) · AudioRecord + STFT 크로마 · 온라인 DTW(연주 듣고 넘기기)
- WebSocket · UDP 브로드캐스트(합주) · NanoHTTPD(웹 업로드)
- GitHub Actions — 커밋마다 빌드 · 단위 테스트(305) · lint, main 푸시마다 에뮬레이터 계측 테스트, 태그로 릴리스

## 📁 저장 위치

```
/storage/emulated/0/Android/data/com.mrgq.pdfviewer/files/PDFs/
├── 악보1.pdf                         ← 웹 업로드 (연결하지 않은 TV)
└── ScoreMate/<앙상블 | 내 악보>/
    ├── 곡 (Full Score).pdf            ← ScoreMate 동기화
    ├── 곡 (Full Score).musicxml       ← 서버 악보 인식 (반주)
    └── 곡 (Full Score).layout.json    ← 서버 악보 분석 (마디 · 보표)
```

앱 전용 폴더만 써서 저장소 권한이 필요 없다.
