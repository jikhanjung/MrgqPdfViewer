# 🎙 음성 명령 사례집

> MRGQ PDF Viewer **v0.7.5-beta.12** 기준. 태블릿 · 휴대폰만 지원합니다(TV 에는 없음).
> 이 문서는 **상황별로 실제로 어떻게 말하고 화면에 무엇이 뜨는지**를 모은 것입니다. 명령 전체 목록과 규칙은 [`Voice_Commands.md`](Voice_Commands.md),
> 설계는 [`devlog/P12`](../devlog/20261009_P12_voice_commands_plan.md), 실제 녹음 평가는 [`devlog/109`](../devlog/20261011_109_voice_real_recordings_eval.md) 에 있습니다.
> 사례의 사람 이름은 지어낸 것입니다.

## 읽는 법

🎙 를 **누른 채로 말하고 떼면**, 단추 위에 두 줄이 뜹니다.

```
🎙 “57마디부터 템포 72”       ← 음성 인식이 받아 적은 말 (여럿 중 고른 것)
✓ 57마디부터 · ♩=72            ← 실행한 것. 실행하지 않았으면 ✗ 와 그 이유
```

아래 사례는 `말 → 화면` 으로 적습니다. 말은 띄어쓰기 · 숫자 표기가 달라도 같습니다("오십칠 마디부터" = "57마디부터").

## 0. 가장 자주 쓰는 말

| 하고 싶은 것 | 말 | 화면 |
|---|---|---|
| 그 마디부터 바로 | **57마디부터** | ✓ 57마디부터 |

| 고른 곳(또는 이 화면 첫 마디)에서 시작 | **시작** | ✓ 시작 |
| 멈추기 | 🎙 를 **짧게 톡** (말 없이) · **멈춰** | (조용히 멈춤) · ✓ 정지 |
| 아까 시작한 곳부터 다시 | **다시** | ✓ 다시 |
| 멈춘 곳부터 | **이어서** | ✓ 이어서 |
| 처음부터 | **처음부터** | ✓ 처음부터 |

| 쪽 넘기기 | **다음 쪽** · **3쪽** · **마지막 페이지** | ✓ 다음 쪽 · ✓ 3쪽 · ✓ 마지막 쪽 |

## 1. 혼자 연습

### 1-1. 어려운 구간만 천천히
57마디부터 64마디까지가 어렵다. 천천히 몇 번 돌려 본다.

1. **"템포 60 57마디부터"** → `✓ 57마디부터 · ♩=60` — 빠르기를 바꾸고 57마디에서 예비박 뒤 시작
2. 64마디쯤에서 🎙 를 **짧게 톡** → 멈춤(글자 없음)
3. **"다시"** → `✓ 다시` — 방금 시작한 57마디부터 다시
4. 손에 익으면 **"템포 72 다시"** → `✓ 다시 · ♩=72`

> 🎙 는 **누르는 순간 메트로놈을 멈춥니다.** 그래서 연주 중에 말할 때는 따로 "멈춰"라고 할 필요가 없습니다.

### 1-2. 마디를 먼저 골라 두고 시작
악보를 보면서 시작할 곳을 정한다.

1. **"57마디"** → `✓ 57마디 선택` — 노란 커서만, 아직 시작하지 않음
2. 악기를 잡고 **"시작"** → `✓ 시작` — 예비박 뒤 57마디부터
   - "시작" 대신 그 마디를 한 번 더 탭해도 됩니다

### 1-3. 예비박 바꾸기
1. **"예비박 한 마디"** → `✓ 예비박 1마디` — 다음 시작부터, 모든 곡에 공통
2. **"예비박 두 마디 57마디부터"** → `✓ 57마디부터 · 예비박 2마디`

### 1-4. 쪽 넘기기
| 말 | 화면 |
|---|---|
| 다음 쪽 · 다음 페이지 · 넘겨 | ✓ 다음 쪽 |
| 이전 쪽 · 앞 쪽 | ✓ 이전 쪽 |
| 12페이지 · 십이 쪽 | ✓ 12쪽 |
| 마지막 페이지 | ✓ 마지막 쪽 |
| **5페이지 시작** | ✓ 5쪽 · 시작 — 넘김이 끝나면 그 쪽 첫 마디부터 |

### 1-5. 메트로놈만
| 말 | 화면 |
|---|---|
| 메트로놈 · 메트로놈 시작 · 메트로놈 켜 줘 | ✓ 시작 |
| 메트로놈 꺼 줘 · 메트로놈 정지 · 그만 | ✓ 정지 |

> v0.7.0 의 기록에서 "메트로놈 꺼 줘"가 **시작**된 적이 있습니다("꺼"를 몰랐다). v0.7.5-beta.9 부터 정지입니다.

## 2. 🎤 연주 듣고 넘기기와 함께 (태블릿 · 휴대폰)

연주를 듣고 쪽을 넘겨 주는 기능을 말로 켭니다. **듣는 동안은 마이크를 듣기가 쓰므로 음성 명령이 쉽니다**(🎙 가 흐려짐). 멈추려면 ↑ 메뉴 "🎤 듣기 멈춤".

| 말 | 화면 · 하는 일 |
|---|---|
| **듣기** · 듣고 넘기기 | ✓ 🎤 연주 듣기 — 고른 마디가 있으면 거기, 없으면 이 쪽 첫 마디부터 |
| **130마디부터 듣기** | ✓ 130마디 선택 · 🎤 연주 듣기 — 메트로놈은 켜지 않고 듣기만 |
| **3쪽 듣기** | ✓ 3쪽 · 🎤 연주 듣기 — 넘긴 뒤 그 쪽 첫 마디부터 |
| **처음부터 듣기** | ✓ 🎤 처음부터 듣기 — 첫 쪽으로 넘겨 첫 마디부터 |
| **이어서 듣기** | ✓ 🎤 이어서 듣기 — 지난번 듣기가 멈춘 마디부터 |

### 사례: 1악장을 통으로 연주해 본다
1. 악보 첫 쪽을 열고 **"처음부터 듣기"** → 첫 마디만 연하게 표시되고 기다림 → 치기 시작하면 따라감
2. 중간에 쉬려고 ↑ → "🎤 듣기 멈춤"
3. 다시 하려면 **"이어서 듣기"** → 멈춘 마디가 있는 쪽으로 넘겨 그 마디부터

## 3. 리허설 — 지휘자

지휘자 태블릿에서 말하면 시작 · 정지 · 템포가 **지금의 합주 메시지로 연주자들에게 그대로** 갑니다. 🎙 를 누르는 순간 연주자들 메트로놈도 멈춥니다.

### 3-1. 지적하고 다시
1. 연주 중 🎙 를 누름 → 모두 멈춤
2. 🎙 를 누른 채 "조금 더 부드럽게 갈게요"라고 단원에게 말하고 떼면 → `✗ 명령을 찾지 못했어요` — **명령이 아닌 말은 실행하지 않습니다**
   - 단, **악기 · 단원 이름이 든 말**("여기 첼로가 좀 커요")은 그 파트 명령으로 읽힐 수 있습니다. 대화는 🎙 를 뗀 채로 하세요
3. **"57마디부터"** → `✓ 57마디부터` — 지휘자와 연주자 모두 57마디에서 예비박 뒤 시작

### 3-2. 레터(리허설 마크)로
악보에 네모 · 동그라미 속 **A · B · C** 가 찍혀 있고 PDF 옆에 MusicXML 이 있는 곡(ScoreMate 동기화).

| 말 | 화면 |
|---|---|
| **레터 B** · 레터 비 · 레터 B부터 | ✓ 레터 B — 그 마크가 붙은 마디부터 |
| 리허설 30 | ✓ 레터 30 (번호로 된 마크) |
| 레터 F (없는 마크) | ✗ 레터 F 가 없어요 — 이 악보: A · B · C · D · E |
| 레터 B (MusicXML 이 없는 곡) | ✗ 레터는 MusicXML 이 있는 악보에서만 알아요 — 마디 번호로 말하세요 |

### 3-3. 템포를 바꿔 가며
1. **"템포 80 처음부터"** → `✓ 처음부터 · ♩=80`
2. **"템포 96 이어서"** → `✓ 이어서 · ♩=96` — 멈춘 마디부터 빠르게

> 지휘자는 **늘 총보**입니다. "첼로 파트"라고 하면 `✗ 지휘자는 총보만 봅니다 — 파트 보기는 연주자 · 혼자 연습에서`.

## 4. 파트 보기

내 파트만 잘라 크게 보는 기능을 말로 고릅니다. 다시 전체를 보려면 **"총보"**.

### 4-1. 악기 이름으로
| 말 | 화면 |
|---|---|
| 첼로 파트 · 첼로 | ✓ 첼로 파트 |
| 바이올린 2 · 바이올린 이 · 세컨 바이올린 · 바이올린 투 | ✓ 바이올린 2 파트 |
| 첼로 비올라 파트 | ✓ 첼로 · 비올라 파트 |
| 바이올린 파트 (바이올린이 둘인 악보) | ✗ 바이올린 파트가 여럿이에요 (Violin I, Violin II) — 번호까지 말하세요 |
| 플루트 파트 (없는 악기) | ✗ 플루트 파트가 없어요 — 이 악보: Violin I · Violin II · Viola · Violoncello |

### 4-2. 단원 이름으로 (보표 이름이 사람 이름인 합주 악보)
보표 이름이 "김민수 · 이서연 · 박지훈"인 악보라면:

| 말 | 화면 |
|---|---|
| 민수 파트 · 김민수 · 민수야 | ✓ 김민수 파트 |
| 서연이 파트보 | ✓ 이서연 파트 |
| 민수 서연 파트 | ✓ 김민수 · 이서연 파트 |
| 지훈이 57마디부터 | ✓ 57마디부터 · 박지훈 파트 — 파트로 다시 연 뒤 57마디부터 |
| 영희 파트 (없는 이름) | ✗ '영희' 파트를 이 악보에서 찾지 못했어요 — 이 악보: 김민수 · 이서연 · 박지훈 |

- 음성 인식이 이름을 **모음 하나만 다르게** 적어도 맞춥니다: "민서 파트"(보표 "민수"와 가운데소리만 다름)는 그런 보표가 하나뿐이면 민수.
  실제 기록에서는 "예원 ↔ 예완"처럼 받침 없는 모음 하나가 자주 바뀌었습니다

### 4-3. 보표 번호로 (이름을 못 읽은 악보)
파트 보기 목록에 "보표 1 · 2 · 3"으로 나오는 악보라면:

| 말 | 화면 |
|---|---|
| 보표 1 파트 · 보표 일 · 스태프 원 | ✓ 보표 1 파트 |
| 두 번째 파트 · 세컨드 파트 | ✓ 보표 2 파트 |
| 보표 2 3 파트 · 보표 이 삼 | ✓ 보표 2 · 보표 3 파트 |

## 5. 합주 연주자

연주자는 **쪽 · 파트 · 총보 · 멈춰**만 됩니다. 마디 · 템포 · 시작은 지휘자 몫입니다.

| 말 | 화면 |
|---|---|
| 첼로 파트 · 총보 · 다음 쪽 | ✓ … (그대로 됨) |
| 멈춰 · 🎙 짧게 톡 | 이 기기만 합주 메트로놈에서 빠짐 |
| 57마디부터 | ✗ 마디는 지휘자가 정해요 |
| 템포 80 | ✗ 템포는 지휘자가 정해요 |

## 6. 한 번에 여러 개

설정(템포 · 예비박) → 파트 → 위치 → 시작 순서로 실행합니다. 하나가 안 되면 거기서 멈추고 앞에서 한 것을 알려 줍니다.

| 말 | 화면 |
|---|---|
| 57마디부터 템포 72 | ✓ 57마디부터 · ♩=72 |
| 예비박 한마디 70마디 시작 | ✓ 70마디부터 · 예비박 1마디 |
| 예비박 두 마디 3페이지 시작 | ✓ 3쪽 · 예비박 2마디 · 시작 |
| 첼로 57마디부터 | ✓ 57마디부터 · 첼로 파트 |
| 템포 72 57마디 | ✓ 57마디 선택 · ♩=72 — 고르기만 |

## 7. 일부러 실행하지 않는 말

잘못 실행(엉뚱한 마디로 감)이 못 알아듣는 것보다 훨씬 나쁘므로, 애매하면 실행하지 않고 이유만 보여 줍니다.

| 말 | 화면 | 까닭 |
|---|---|---|
| 57마디 **말고** 58마디 | ✗ '말고 · 아니 · 취소'가 있어 실행하지 않았어요 | 부정이 들렸다 |
| 두 마디 **전**부터 | ✗ '두 마디 전'처럼 상대 위치는 아직 몰라요 — 마디 번호로 말하세요 | 상대 위치 |
| 57마디 3쪽 | ✗ 위치나 템포가 둘이에요 — 하나만 말하세요 | 위치가 둘 |
| 멈춰 57마디부터 | ✗ 위치나 템포가 둘이에요 — 하나만 말하세요 | 멈춤과 시작이 함께 |
| 2악장 57마디 | ✗ 무엇의 수인지 모르는 수가 있어요 — '57마디'처럼 단위를 붙이세요 | 단위 없는 수 |
| 템포 300 | ✗ 템포 300 은 쓸 수 없어요 (20 ~ 240) | 범위 밖 |
| 500마디부터 (없는 마디) | ✗ 500마디가 없어요 (1 ~ 240) | 악보에 없음 |
| 다시 듣기 | ✗ 위치나 템포가 둘이에요 — 하나만 말하세요 | 어디부터인지 모호 |
| (단원과 하는 대화) "누르고 있다가 그 전에는 안 하고" | ✗ '두 마디 전'처럼 상대 위치는… | 명령이 아님 — 실제 기록 |

## 8. 실제 기록에서 — 음성 인식이 이렇게 받아 적어도

태블릿의 기록(115건, 2026-10-09 ~ 11)에서 음성 인식이 실제로 받아 적은 후보들과 지금(v0.7.5-beta.12) 앱이 하는 일입니다.
음성 인식은 후보를 여럿(가능성 높은 순) 주고, 앱은 그중 **명령으로 읽히고 값이 쓸 수 있는 범위인 첫 후보**를 고릅니다.

| 말한 것 | 받아 적힌 후보 | 지금 |
|---|---|---|
| 115마디 (빨리 떼서 끝이 잘림) | "115 마" · "115마" · "115m" | ✓ 115마디 선택 |
| 템포 80 | "템포 8" · "템포 80" | ✓ ♩=80 — 범위 밖인 8 대신 둘째 후보 |
| 템포 90 | "템포 90" · "템포 9" · "템퍼 90" | ✓ ♩=90 |
| 총보 | "총복" · "충북" | ✓ 총보 |
| 총보 | "청보" · "총보" · "충보" | ✓ 총보 |
| 보표 2 파트 | "도표이 파트" · "도표 2 파트" | ✓ 보표 2 파트 |
| 보표 2 3 파트 | "목표 23 파트" · "목표 2 3 파트" | ✓ 보표 2 · 보표 3 파트 (보표가 3개인 악보) |
| staff one 파트보 | "스테프원 파트보" · "스테프원 파트버" | ✓ 보표 1 파트 |
| 기타 원 파트보 | "기타 원 파트 보" · "기타 1 파트 보" | ✓ 기타 1 파트 |
| 기타 퍼스트 파트보 | "기타 퍼스트 파트보" · "기타포스트 파트보" | ✓ 기타 1 파트 |
| 세컨드 파트보 | "세컨드 파트 보" · "세컨드 파트 보험" | ✓ 보표 2 파트 |
| (이름) 파트 | "○○ 하트" · "○○ 파트" · "○○ 파크" | ✓ ○○ 파트 — "파트"는 첫 후보가 아니어도 된다 |
| 마지막 페이지 | "마지막 페이지" · "마지막 페인트" | ✓ 마지막 쪽 |

## 9. 잘 알아듣게 말하는 요령

- **누르고 → 말하고 → 떼기.** 떼고 0.6초 더 들으니 바로 떼도 됩니다. 단, 누르자마자 말을 시작하면 첫 음절이 잘릴 수 있어 아주 잠깐 뒤에 말하면 좋습니다
- **수에는 단위를 붙입니다**: "57"보다 "57마디", "3"보다 "3쪽". 수만 말하면 마디 고르기로 읽습니다
- **한 번에 위치는 하나**: "57마디 3쪽"은 실행하지 않습니다
- **🎙 를 누른 채 대화하지 않기**: 악기 · 단원 이름이 든 말("첼로가 커요", "민수 씨 좋아요")은 그 파트 보기로 읽힐 수 있습니다
- 파트는 **악기 + 번호**("바이올린 2"), 같은 악기가 여럿인 악보에서 번호를 빼면 되묻습니다
- 이름 보표는 그 악보의 **파트 보기 목록에 보이는 이름**으로 — 목록에 "보표 1"로만 나오면 "보표 1"
- 시끄러운 곳(악기 소리)에서는 단말기에 가까이, 또박또박. 소음 속 인식은 아직 평가 중입니다
- 인터넷이 필요합니다(기기 음성 인식) — "음성 인식 서버에 닿지 않아요"가 뜨면 와이파이 확인

## 10. 화면에 뜨는 말 — 무슨 뜻인가

| 화면 | 뜻 · 할 일 |
|---|---|
| 🎙 듣는 중… | 누르고 있는 동안 |
| 🎙 알아듣는 중… | 뗀 뒤 결과를 기다리는 중 |
| ✗ 못 알아들었어요 — 누른 채로 말하세요 | 말이 들리지 않았거나 글자로 바꾸지 못함 |
| ✗ 명령을 찾지 못했어요 | 글자는 받았지만 명령이 아님 |
| ✗ 음성 인식 서버에 닿지 않아요 — 인터넷 연결을 확인하세요 | 와이파이 확인 |
| 🎤 연주 추적을 멈춘 뒤에 말하세요 | 🎤 듣기 중에는 음성 명령을 쓸 수 없음 |
| ✗ 한국어 음성 인식을 쓸 수 없어요 — … 마이크 권한을 확인하세요 | 음성 인식 앱(음성 인식 및 합성)의 마이크 권한 |
| ✗ 음성 인식을 시작하지 못했어요 — … 음성 입력을 확인하세요 | 기기의 기본 음성 입력이 비어 있음 |
| ✗ 다시 시작할 마디가 없어요 — 이 곡에서 아직 시작한 적이 없어요 | "다시"는 한 번 시작한 뒤에 |
| ✗ 이어서 할 마디가 없어요 — 멈춘 적이 없어요 | "이어서"는 한 번 멈춘 뒤에 |
| ✗ 이 악보는 마디 · 박자표를 읽지 못해 마디로 갈 수 없어요 | 스캔 악보 등 — 쪽 명령은 됨 |
| ✗ 지휘자가 방금 넘겨 잠시 넘길 수 없어요 | 합주 연주자 — 잠시 뒤 다시 |

음성 인식 앱이 없거나 켜지지 않을 때의 설치 · 설정 방법은 [`Voice_Commands.md` — 음성 인식이 켜지지 않을 때](Voice_Commands.md#음성-인식이-켜지지-않을-때).
