# 용어집 · Glossary (한국어 → English)

앱 화면 번역의 기준 (P18). 새 글을 옮길 때 이 표를 따르고, 없는 용어는 여기에 먼저 더한다. 사용자가 영어 화면을 훑어 고치면 이 표도 고친다.

## 문체

- 버튼 · 메뉴는 짧게 Title Case 없이 문장형("Check for updates", "Start from measure 57")
- 한국어의 " · " 나열은 영어에서 ", " 또는 " · " 그대로(좁은 칸)
- 이모지는 두 언어가 같다(글 밖에 둔다)
