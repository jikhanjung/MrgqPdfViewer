# 악보 화면 메뉴

악보 화면 안에서 여는 메뉴 · 대화상자의 지금 모습 (2026-10-10, P13 1 ~ 3단계 뒤).
정리 원칙 · 남은 단계는 [devlog P13](../devlog/20261010_P13_viewer_menu_reorg_plan.md). 메뉴를 바꾸면 이 문서도 고친다.

- **↑ = 연주**: 소리와 시간 — 시작 · 멈춤 · 🎤 듣기 · 메트로놈 · 반주
- **길게 = 보기**: 화면에 무엇을 어떻게 — 파트 · 마디 박스 · 메모 · 두 쪽 · 자르기
- 한 항목은 한 메뉴에만. 그 기기 · 역할에서 못 쓰는 줄은 숨긴다

## 여는 법

| 메뉴 | TV (리모컨) | 태블릿 · 휴대폰 (터치) | 코드 |
|---|---|---|---|
| **연주** | ↑ | 가운데 두 번 탭 (마디를 고르는 중이면 어디든 두 번 탭) | `showMetronomeMenu` |
| **연주** (합주 연주자) | ↑ | 가운데 두 번 탭 | `showPerformerEnsembleMenu` |
| **보기** | OK 길게 (0.8초) | 길게 누르기 — 🎤 듣는 중 마디 위면 대신 "그 마디부터 다시 맞춤" | `showPdfDisplayOptions` |

- 둘 다 열면 악보 연동이 **일시정지**한다. 연주 메뉴를 아무것도 고르지 않고 닫으면 정지
- 일시정지 중 메뉴를 모두 닫으면 연주 메뉴가 다시 뜬다(이어서 · 마디 골라 다시 · 정지, #053)

## 1. 연주 (↑)

제목 "연주" (일시정지면 "연주 — 일시정지").

| 순서 | 줄 | 보일 때 |
|---|---|---|
| 1 | 🎤 연주 듣고 넘기기 — 이 쪽 첫 마디부터 / 🎤 N마디부터 연주 듣고 넘기기 / 🎤 듣기 멈춤 | 마이크로 들을 수 있는 기기(태블릿 · 휴대폰) |
| 2 | 상태 줄 — 아래 표 | 늘 |
| 3 | 메트로놈 설정… | 늘 |
| 4 | 반주 (MusicXML): 켜짐 · 크기 n% | PDF 옆에 `.musicxml` 이 있을 때 |

상태 줄:

| 상태 | 줄 |
|---|---|
| 마디를 고르는 중 | ▶ N마디부터 시작 (예비박 n마디 뒤) · 마디 고르기 취소 |
| 일시정지 | 이어서 — N번 마디부터 (예비박 n마디 뒤) · 마디 골라 다시 시작 · 정지 |
| 메트로놈이 도는 중 | 정지 |
| 멈춤 | 시작 — 악보에서 마디 고르기 |

## 2. 연주 — 합주 연주자 (↑)

제목은 상태로: "연주 — 지휘자를 따라가는 중" · "— 이 기기는 빠져 있음" · "— 지휘자가 시작하면 따라갑니다".

1. 이 기기만 빠지기 (따라가는 중) / 지휘자 연주에 다시 합류 — 지금 연주 중인 마디로 (빠져 있을 때)
2. 메트로놈 소리: 끔 / 켬 — 누르면 바로 바뀐다 (설정 → 협업 모드 "합주 메트로놈 소리 (연주자)"와 같은 값)

템포 · 박자 · 시작은 지휘자를 따른다. 파트 보기 · 메모는 연주자도 보기 메뉴에서.

## 3. 보기 (OK 길게 · 길게 누르기)

제목 "보기", 아래에 "닫기".

| 순서 | 줄 | 보일 때 | 누르면 |
|---|---|---|---|
| 1 | 파트 보기: (지금 파트 · 전체 악보) | 지휘자가 아닐 때 | 파트 보기 대화상자 |
| 2 | 마디 박스: 켜짐/꺼짐 | 늘 | 바로 바뀜 |
| 3 | 메모 보이기: 켜짐/꺼짐 | 늘 | 바로 바뀜 |
| 4 | ✏️ 메모 쓰기 / ✏️ 메모 끝 | 메모를 쓸 수 있는 기기(태블릿 · 휴대폰) | 메모 모드 |
| 5 | 두 쪽 보기: 두 쪽 / 한 쪽 | TV 가로 (세로 화면 · 휴대폰은 숨김) | 두 페이지씩 / 한 페이지씩 + "이 선택을 기억하기" |
| 6 | 위/아래 자르기… (두 쪽이면 "자르기 · 여백…") | 늘 | 위 · 아래 슬라이더(0~15%), 두 쪽이면 가운데 여백(0~15%)도. 초기화 · 위/아래 5%, 적용하면 이 메뉴로 돌아옴 |
| 7 | 회전: 기기 회전 / 가로 / 세로 | 휴대폰 | 고르면 바로 그 방향으로 (설정 → 표시 모드와 같은 값) |

## 4. 밑 대화상자

- **메트로놈 설정** (`showMetronomeDialog` · `buildMetronomeDialog`, 템포 · 박자는 파일별) — 아래 단추 시작(도는 중이면 정지) · 닫기
  - 박자 → 상세: 흔한 박자, 분자 · 분모 직접, 세는 단위(8분음표 6박 / 점4분음표 2박)
  - 속도 → 상세: 세밀 조절
  - 소리 크기 → 상세: 클릭음 켬 / 끔
  - **예비박: [한 마디] [두 마디]** — 첫 화면, 모든 파일 공통
  - 박자가 바뀌는 곡이면 구간 목록 → 구간마다 같은 짜임(이어받기 · 세는 단위)
- **반주** (`showAccompanimentDialog`) — 켜기, 소리 크기(클릭과 따로)
- **파트 보기** (`showPartViewDialog`) — 보표 여러 개 체크 → 보기 · 전체 악보 · 닫기
- **페이지 표시 모드** (`showTwoPageModeDialog`) — 두 페이지씩 / 한 페이지씩, 기억하기
- **위/아래 자르기 · 가운데 여백** (`showClippingDialog`, 파일별) — 움직이면 0.2초 뒤 미리 보임, 취소하면 되돌림
- **회전** (`showPhoneOrientationDialog`, 휴대폰) — 기기 회전 · 가로 · 세로

## 5. 악보 화면과 관련된 앱 설정 (설정 화면)

| 설정 → | 항목 |
|---|---|
| 애니메이션 & 사운드 | 페이지 전환 애니메이션 · 페이지 넘기기 사운드 · 사운드 볼륨 |
| 표시 모드 | 회전 모드 (악보 화면, 휴대폰) · 파일별 표시 모드 목록 · 초기화 |
| 협업 모드 | 합주 메트로놈 소리 (연주자) — 연주자 메뉴와 같은 값 · 동기 페이지 넘김 · 예약 시간 · 입력 차단 시간 |
| 앱 정보 | 🎙 음성 명령 · 👂 계속 듣기 (꺼 둠, #093) · 🗣 호출어 (숨김) |

## 6. 코드에만 있는 것

- **연주자 메트로놈 설정 대화상자**(`showPerformerMetronomeSettings`) — 연주자 메뉴의 소리 줄이 바로 바꾸게 되어 지금은 연주자가 메트로놈 설정을 열 때(`showMetronomeDialog` 의 가드)만 쓰인다
